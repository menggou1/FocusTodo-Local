## 实现范围

按计划交付紧凑 JSON、无损 Gzip 外层编码、旧 v1/v2 JSON 兼容、备份范围与体积分析、无 Web Locks 的维护归属保护。保持 `PomodoroDB6` v3，不迁移用户数据库。

默认完整备份保留项目、任务、子任务、专注记录、设置、图片和计时快照；导入后的活动计时仍进入恢复确认，不自动计入备份后的离线时间。不含壁纸是显式可选范围，恢复时回退到内置主题。导入前、删除前的自动安全备份始终完整，下载发起不代表磁盘保存完成。

## 兼容与限制

- 新版读取旧 JSON；旧版不读取 Gzip，跨版本排查可用普通 JSON。
- Gzip 不改变备份业务格式版本或数据库版本。不能解压、损坏、未知格式及超限文件在覆盖之前拒绝。
- 主题图片仍以 data URL 保存在 localStorage。Blob 迁移、ZIP 独立资源、去重与缩略图重建延后；大图片恢复仍受浏览器 localStorage 配额限制。
- 没有可确认的磁盘持久化状态；用户需检查浏览器下载文件。

- 发布元信息生成、8 个脚本语法检查通过；48 项 Node 检查中 47 项通过、1 项 POSIX 包装器用例在 Windows 按平台跳过，0 失败。
- 47 项应用浏览器用例全部通过；包含 Gzip 实际下载保存到临时开发目录、文件选择器从该磁盘路径导回、壁纸真实显示、不含壁纸主题回退、自动安全备份完整、无压缩 API 的 JSON 降级和窄屏深色界面。此为自动化落盘链路，未把它标作人工操作。
- 7 项无 Web Locks 维护场景通过：导入/导入、导入/删除竞争，第三页启动不清标记，计时/旧写入被阻止，拥有者页面关闭后的接管，设置回滚失败与刷新恢复；覆盖有/无 BroadcastChannel。拥有者暂停时等待，不按超时接管。
- 原有计时恢复、事务回滚、跨页初始化、任务进度和删除确认回归保留；运行证据在 [results.json](https://github.com/menggou1/FocusTodo-Local/blob/main/docs/acceptance/results.json)。
- ZIP 和 tar.gz 校验和、解压后在空格/中文路径运行及包内文档链接检查通过，无需 npm/Git；版本不匹配的标签被拒绝。

## 容量测量

使用生成数据，Windows 11 / Edge 155.0.4283.62 / i5-11260H / 16 GB 内存 / Node 24.16.0；每种规模各跑一次，不承诺固定耗时。脚本为 `npm run benchmark:backup`，完整数据见 [backup-performance.json](https://github.com/menggou1/FocusTodo-Local/blob/main/docs/acceptance/backup-performance.json)。全程使用隔离浏览器，不读取私人备份。

| 样本 | 原始字节 | Gzip 字节 | 导出快照 ms | 压缩 ms | 解码 ms | 业务校验 ms | 恢复 ms | 结果 |
|---|---:|---:|---:|---:|---:|---:|---:|---|
| 任务/历史 ~1 MB | 998512 | 82531 | 39.3 | 24 | 5.3 | 2.7 | 213.6 | 恢复及字段一致性通过 |
| 任务/历史 ~10 MB | 9984230 | 798741 | 309.6 | 223.9 | 44.1 | 52.8 | 2503.9 | 恢复及字段一致性通过 |
| 任务/历史 ~50 MB | 49916619 | 3957494 | 1353.5 | 1045.9 | 219.8 | 299.1 | 14672.5 | 恢复及字段一致性通过 |
| 图片为主 ~1 MB | 1006899 | 726350 | 5.6 | 41.6 | 13.7 | 4.8 | 52.2 | 恢复及字段一致性通过 |
| 图片为主 ~10 MB | 10043079 | 7521579 | 未写入 | 346.8 | 119.9 | 34.7 | 247.3 | 配额拒绝，回滚通过 |
| 图片为主 ~50 MB | 50183279 | 37705986 | 未写入 | 2183.7 | 398.9 | 124.5 | 973.9 | 配额拒绝，回滚通过 |

任务/历史样本完整核对 ID、关联、字段、总专注秒数；1 MB 图片样本保留原图数据。10/50 MB 图片样本无法写入 localStorage，压缩/解压从生成对象测量，不能称为数据库导出或支持该恢复容量。

50 MB 任务/历史恢复约 14.7 秒，观测最大主线程间隔 3.24 秒，采样 JS 堆约 611 MB；50 MB 图片失败样本采样约 1,040 MB。内存是阶段与 20 ms 间隔采样的 JS 堆，排除进程/native/Blob 内存，可能漏掉阻塞期间峰值；界面响应数据来自运行真实存储/编码 API 的隔离 fixture，并非完整 React 页面吞吐量。Gzip 为流式压缩与有界解压，但快照、JSON 和业务校验仍整包处理；大包可能短时卡顿。后续再评估 Worker/分批读取；本版不改变一致快照和日志事务语义。
