# FocusTodo 7.1.1-local.1.4.0 语言选择、英文适配与本地功能定位

[更新记录](../CHANGELOG.md) · [English report](en/UPDATE-7.1.1-local.1.4.0.md) · [统一待办与功能设计](BACKLOG.md)

日期：2026-10-25（Asia/Shanghai），作者：Lexible，Tag：`1.4.0`。

## 已交付功能

- 设置 → 通用新增语言选择，只列跟随系统、简体中文、English。其他既有部分翻译仅通过跟随系统启用，区域语言选可用的语言/变体，再回退英文。
- 本地备份、主题、计时恢复、删除确认、错误和历史更新条目提供英文；原翻译缺项通过完整词库回退，未知项使用可读提示，不暴露内部键名。已有用户任务、备注、文件名不进行 DOM 自动翻译。
- 语言偏好随备份保存，重置保留界面语言。切换语言刷新同一地址，不移动浏览器数据；默认本地用户名随显示语言变化，不改写自定义用户名。
- 通用设置新增主动通知授权及测试入口，显示未授权、允许、拒绝和不支持状态，返回窗口时更新权限状态；启动不自动请求授权。完成统一待办中的 E05、E06，并从清单删除。
- 新增英文使用、维护、架构、统一待办及各版本英文技术报告，便携包包含英文文档。英文历史报告是技术摘要，保留交付行为与公开证据；中文原报告保留。
- 明确小组、在线排名和旧森林入口不属于本地版；旧备份启用标记不会恢复这些入口，停用隐藏森林的后台奖励初始化。兼容表和历史数据保留。

## 本地功能方案汇报

方案集中在[统一清单的本地功能设计](BACKLOG.md#本地版本功能设计方案)，英文有对应说明。小组永久不恢复；森林建议改为默认关闭的个人成长页，从有效专注秒数派生树木、趋势和个人里程碑，按实际片段分配自然日，不建立服务器阳光或社交排名。该成长页仍是方案，本轮没有擅自恢复入口。

## 验证与发布

本地重点检查三个语言流程：中文切 English 与显式通知授权、未知系统语言回退英文且不暴露键、法语区域系统语言保留可用控件。检查英文备份布局、中文现有界面与生成元信息；不重复大数据库性能或人工长时间验收。
