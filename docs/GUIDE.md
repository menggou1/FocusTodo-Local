# FocusTodo 本地版使用教程

[返回首页](../README.md) · [English](en/GUIDE.md) · [更新记录](../CHANGELOG.md)

这篇教程按主界面、任务、计时、报表和设置介绍浏览器本地版，并补充日程、森林和备份。组织方式参考 [Lexible 的 Windows 版功能介绍](https://zhuanlan.zhihu.com/p/31498089)，操作以本地版当前界面为准。截图使用隔离环境中的测试数据，具体日期和数量仅供示例。

## 先认识三个概念

- **番茄工作法**：把事情拆成可执行的小任务，在一段专注时间后休息，再继续下一轮。时间长度可以按自己的习惯调整。
- **任务**：一次要完成的具体事情，例如“整理本章笔记”。可以为它估计番茄数、设置日期、提醒、子任务和备注。
- **清单**：把相关任务放在一起的容器，例如“学习”或“工作”。系统清单按日期或状态汇总任务，自定义清单用于自己分类。

## 一、打开与认识主界面

在线打开 [GitHub Pages](https://menggou1.github.io/FocusTodo-Local/)，或按[首页快速开始](../README.md#快速开始)启动便携包。首次打开会生成本地用户，无需注册或登录。请固定使用同一个浏览器和地址；不同浏览器、域名或端口的数据彼此独立。

![主界面与系统清单](guide-images/home.png)

- **左侧**：搜索、今天、明天、本周、已计划、日程、已完成，以及自定义清单。底部可创建清单；拖动自定义清单可调整顺序。系统清单可在设置里的清单管理中排序或隐藏。
- **中间**：当前清单的统计、添加任务输入框和任务列表。今天等系统视图按日期或状态聚合；进入自定义清单可专注于该清单。
- **右上角**：森林、报表、通知和设置入口。具体图标与窗口宽度会影响布局。
- **底部**：小型计时器，方便在查看列表时控制专注。

## 二、创建和管理任务

1. 选择左侧的清单，在顶部输入框写下任务名称并按 Enter。可先选择预计番茄数及清单或日期，再保存。
2. 点击任务名称打开详情，按需要编辑标题、预计番茄、到期日、所属清单、提醒、重复、子任务和备注。子任务输入后按 Enter；备注编辑后点击其他位置保存。
3. 点击任务左侧的完成圆圈标记完成；任务旁的播放按钮可以针对该任务开始计时。右键任务可查看其他操作；拖动任务可调整列表顺序。
4. 在“已完成”中回顾已完成任务，或在支持的列表中展开已完成项。需要恢复时使用取消完成操作；删除前先确认选择的是正确任务。

![任务详情与编辑字段](guide-images/task.png)

**日期与提醒的区别**：到期日用于安排和分类，提醒是在指定时间提示你。提醒到时会出现在右上角铃铛中；已读、完成、删除或更改提醒后，角标会随之更新。桌面通知还需在“设置 → 通用”中授权，并允许浏览器及系统通知。

![任务提醒与更新通知](guide-images/reminders.png)

## 三、开始一次专注

1. 点击任务旁的播放按钮，或直接在底部计时器开始不关联任务的专注。
2. 计时界面按当前状态提供开始、暂停、继续、停止或休息等操作。可在小型计时器与展开的计时界面之间切换。
3. 完成一轮后按提示休息；在“设置 → 番茄钟”调整番茄、短休息、长休息及自动开始选项。
4. 在展开界面取消任务关联只会解除当前计时与任务的关联，任务仍在清单中。停止会归零，并保存达到有效时长门槛的片段。

![展开的计时界面](guide-images/timer.png)

如果运行中的会话中断超过五分钟，恢复时会询问是否计入中断时间，请按实际情况选择；等待确认期间不会继续计时。

## 四、用日程安排时间

选择左侧“日程”，通过日期、前后箭头和视图选择器查看安排与已完成记录。日视图中可在空白时间段拖选或双击，填写任务名称、日期、时长、预计番茄和清单后保存；取消不会创建任务。已有安排可以拖动、调整长度、打开详情，或通过安排上的播放按钮开始专注。重叠安排会分列显示，月视图可滚动并打开日期。

![日视图中的安排与记录](guide-images/calendar.png)

![日程快速创建任务](guide-images/calendar-create.png)

## 五、查看报表和森林

点击右上角的报表图标，可回顾专注时间、任务完成情况、清单时间分布和趋势。统计反映已保存的记录；不关联任务的专注也可以被记录。

![报表中的统计和图表](guide-images/report.png)

在“设置 → 通用”开启专注森林，再点击右上角森林图标。专注记录、完成任务和本地登录可产生阳光；阳光成熟后点击收取，过期后不能收取。界面内攻略介绍具体规则。成就按累计专注、完成任务和有专注记录的自然日解锁，奖励只发放一次。森林与成就均保存在本机；小组和在线排名不属于本地版。

![本地森林与阳光示例](guide-images/forest.png)

## 六、设置、备份与迁移

- **通用**：选择语言、控制森林及申请或测试桌面通知。
- **番茄钟与声音**：调整时长、休息、提示音和背景声音；浏览器或系统可能限制声音及通知。
- **外观与清单管理**：选择主题、上传壁纸，管理系统清单显示和顺序。
- **账号**：修改本地昵称和头像，导出、导入或删除本地数据。这里不提供账号登录或跨设备自动同步。
- **关于**：查看版本、作者，打开仓库或本教程。

![账号设置与备份入口](guide-images/account.png)

![关于页的仓库和教程入口](guide-images/about.png)

### 导出和导入

1. 进入“设置 → 账号 → 导出数据”。默认完整备份为 `.json.gz`，也可以选择普通 JSON 或不含壁纸；重要操作前建议保留完整备份。
2. 检查浏览器下载目录，确认文件已保存，并将备份放到可靠的位置。清除站点数据、换浏览器或换地址前尤其需要备份。
3. 在目标浏览器和地址打开应用，进入“设置 → 账号 → 导入数据”，选择备份，查看显示的范围后再确认覆盖。线上 Pages 与本机地址互不共享数据，通过此方法迁移。
4. 导入和删除前会发起完整安全备份；下载开始不等于文件已永久保存，仍需检查下载结果。删除操作需要等待并确认。

应用支持旧版 JSON 和 Gzip 内容识别；Gzip 导入需要浏览器解压能力，文件及解压数据各有 128 MB 上限。图片受浏览器存储配额限制。不含壁纸的备份恢复后使用内置主题。

## 常见问题

**更换端口后任务不见了？** 浏览器按地址隔离存储。回到原地址导出，再到新地址导入；不要清理原地址的数据。

**为什么没有提醒或声音？** 检查任务提醒时间、应用设置、浏览器站点权限和系统通知设置；背景声音还可能受到浏览器播放策略影响。

**哪里查看版本变化？** 右上角铃铛提供简短更新详情；完整历史和验证记录见[更新记录](../CHANGELOG.md)。
