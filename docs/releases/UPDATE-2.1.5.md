# FocusTodo 2.1.5

[更新记录](../CHANGELOG.md) · [English](../en/releases/UPDATE-2.1.5.md)

准备日期 2026-11-23（Asia/Shanghai），作者 Lexible。此修订版围绕「关于页面视觉统一与发布流程优化」。

## 设置中的关于页

关于页沿用 1.9.4 的标签列、内容列和设置行。版本、作者、上游项目、MIT 与第三方声明、本地数据说明各自占一行。窄窗口可换行和滚动。

作者旁恢复原来的 24×24 GitHub 图标。六个官方下载图标使用相同的背景高亮和可见键盘焦点。「下载官方版本」使用普通设置标签，六个平台图标保留官方下载链接。下载行、官方网站 www.focustodo.cn 和支持正版说明依次排列，明确区分本地项目和 Focus To-Do 官方发行。

## 开发与发布

中英文维护指南明确主题化开发和语义化版本号。当前开发批次使用可清空的模板，未完成事项继续在 [BACKLOG](../BACKLOG.md) 维护。

发布 CI 按引用身份选择同 SHA 的原始完整矩阵与未过期附件。预检比对当前构建和原始附件的文件内容，并运行解压启动检查。独立门禁再次校验证据，发布和 Pages 继续执行各自的版本、来源和附件门禁。证据无法验证时运行完整矩阵。预检与独立门禁的 Actions 摘要保留原始 SHA、运行编号和附件摘要。
