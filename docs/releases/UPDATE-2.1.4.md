# FocusTodo 2.1.4

[更新记录](../CHANGELOG.md) · [English](../en/releases/UPDATE-2.1.4.md)

准备日期为 2026-11-22（Asia/Shanghai），作者为 Lexible。2.1.4 是 2.1.3 之后的修订版本。

## 备份、计时事务和提醒

- 备份检查与恢复共用目标历史校验。旧版 JSON 和 v2 Gzip 中损坏的目标记录或非文本名称会在写入和生成安全备份前被拒绝。旧版记录省略名称时仍可恢复，支持搜索并保留扩展字段。
- 完成或删除任务时，如果解除计时关联首次发现待确认的中断，任务、子任务和计时会话的写入一起回滚。服务合同复验在确认中断后重试，仅保留获确认的 60 秒专注记录。
- 每日专注目标按本地自然日更新。编辑纽约秋季回拨日第二次出现的本地时刻时，修改日程或专注记录的时长会保留原有开始时间戳。日历选日写入所选本地日期，释放到无效区域保留原日程。
- 两个标签页在同一存储锁下合并提醒已读记录。系统通知构造失败时，应用内提醒保持未读，后续提醒继续调度。同一页面对每条到期提醒只尝试一次系统通知。

## 计时器与设置

- 独立迷你计时器恢复 1.9.4 的背景亮度、入场淡入和两侧窗口按钮。缩放时计时控件整体居中，主窗与小窗共享计时会话。原生小窗对照涵盖明暗主题、147×58 和 232×58、尺寸切换、专注、暂停、休息和重新打开。
- 设置的八个下拉按钮在可见控件内响应点击。交互回归涵盖行内文字、空白位置、焦点、键盘和触控。外观中的壁纸区域更名为「背景」，沿用已有设置键和选择行为。
- 计时侧栏恢复 330px 卡片随侧栏滑动的 150ms 线性收展。组件松手后从当前预览位置沿双轴衔接 180ms 的 `ease-out` 排序过渡。主动拖动项保持在正确层级，其他组件平滑让位，确认后才保存布局。专项对照检查动画中途反向、斜向放置、越界回弹及滚动边界。
- 关于页展示本地版本、作者、来源项目、离线存储、仓库和许可。帮助和反馈入口移除，官方版本下载移到末尾并指向 Focus To-Do 官方下载区。更新详情固定应用磁贴、标题和确认区，条目通过应用的共享滚动条滚动，沿用历史和最新条目的已读规则。

## 报表与旧版对照

- 专注时长柱图先显示按优先级和任务顺序排列的任务，再显示按保存顺序排列的自定义清单。日、周、月、年采用相同投影，保留原始聚合秒数。短分段共享设备像素边界，Windows Chromium 的 DPR 1 和 2 均验证了 90 秒绿色分段的精确颜色。
- 设置与 1.9.4 对照中，白噪音区域的垂直位移对应移入计时设置的任务完成提示音行。对齐视区后核对了按钮、图标和音量滑块。导入、导出固定标题与滚动正文恢复原有总间距，英文深色导入预览对照的三个几何差异已消除。
- 报表番茄记录的共享滚动条跟随记录视区，并裁切在圆角内。2,920 条合成记录覆盖滚轮、键盘、拖动滚动条和内外滚动交接，滚动期间未重置 Canvas 尺寸。保存已有记录后直接重绘分段，揭示进度保持为 1。
