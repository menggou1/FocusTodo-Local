# FocusTodo 2.2.0

[更新记录](../CHANGELOG.md) · [English](../en/releases/UPDATE-2.2.0.md)

准备日期 2026-11-26（Asia/Shanghai），作者 Lexible。本版主题为主工作区交互与搜索优化。

## 主工作区

- 创建输入框沿用 1.9.4 的明暗主题文字颜色。主任务和子任务的加号与回车使用同一提交入口。
- 创建框、日期选择器和提交使用一致的已保存默认日期。明确确认「待定」保存截止日 `0`。合成旧备份中的 2026-09-29 默认值和历史任务日期按原值读取。详情选择器高亮当前快捷项，第三项提示「未来七天」。
- 清单分组标题及已完成区标题和开关与任务共用布局过渡，沿用原有任务运动曲线、时长和轨迹。成功放置到侧栏且任务离开当前工作区时，拖影朝放置目标退场。取消及失败时回接当前列表。
- 拖动时标识可放置的清单、标签、日期和优先级。按清单分组的清单夹只允许在同一清单内排序。其他清单任务变灰，悬停时提示通过左侧清单移动。日期聚合区所有任务变灰并拒绝内部排序。
- 报表顶部总计、本周、今日默认显示小时及分钟，悬停时显示对应的番茄数与标题。详情与右键菜单共用删除确认、重复任务选项及任务、子任务和记录处理。

## 搜索

任务快照按父任务索引活动子任务，缓存规范化查询结果，快照刷新会使缓存失效。搜索继续匹配标题、备注、标签和子任务，保留已完成任务与缺少清单归属的匹配项。按清单顺序分组，组内沿用任务顺序，隐藏顶部统计、创建及排序入口。

输入 300 毫秒后提交，回车立即提交。输入法合成期间保留草稿。通知和其他导航取消待提交搜索。更新关键词后保留仍匹配的任务详情，清空后按 Escape 可立即返回来源视图。
