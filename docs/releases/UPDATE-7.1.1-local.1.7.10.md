## 本次交付

- 关于页提供中英文图文教程，介绍任务、计时、报表、设置、日程、森林和备份，配图只使用隔离测试数据。便携包包含教程与配图。
- 静态服务器与浏览器验收服务器统一通过 Node `pipeline` 发送文件。浏览器关闭上下文、刷新或取消图片/字体下载时，源文件流随响应一起销毁，避免暂停的流继续占用文件句柄。异步文件查询完成时也检查响应是否已关闭。
- 日程启动失败会保存请求失败、页面错误、启动屏幕与挂载状态和截图，截图进入 CI 实际上传的证据目录；发现启动错误时直接报错，保留原等待阈值和业务断言。
- 删除没有 Release 或未通过全部流程的独立版本报告和全部旧报告跳转页，既有文件链接直接指向保留报告或本文。应用更新记录也不再把失败候选列为正式历史。

## 发布判定与验证

正式版本必须合入 main 并推送，同一提交的 main 六组测试、Pages 部署和标签六组测试及 Release 发布全部成功。任一步失败，下一次修复先递增版本号，移除失败版本独立报告及更新项，将有效内容迁入下一版；已经推送的标签保留且不覆盖。即使 Release 已存在，只要有要求流程失败，也不能作为正式版本。

本次执行版本生成、语法、Node、完整隔离浏览器、发布门禁、Pages 白名单、便携包与 ZIP/tar.gz 解压启动检查。最终公开结果见 [main 测试](https://github.com/menggou1/FocusTodo-Local/actions/workflows/ci.yml?query=branch%3Amain)、[1.7.10 标签发布](https://github.com/menggou1/FocusTodo-Local/actions/workflows/ci.yml?query=branch%3A1.7.10)、[Pages](https://github.com/menggou1/FocusTodo-Local/actions/workflows/pages.yml)及 [Release](https://github.com/menggou1/FocusTodo-Local/releases/tag/1.7.10)。本报告随候选提交进入仓库，仅在这些流程全部成功并创建 Release 后留存为正式版本报告。

50 MB 任务/历史恢复约 14.7 秒，观测最大主线程间隔 3.24 秒，采样 JS 堆约 611 MB；50 MB 图片失败样本采样约 1,040 MB。内存是阶段与 20 ms 间隔采样的 JS 堆，排除进程/native/Blob 内存，可能漏掉阻塞期间峰值；界面响应数据来自运行真实存储/编码 API 的隔离 fixture，并非完整 React 页面吞吐量。Gzip 为流式压缩与有界解压，但快照、JSON 和业务校验仍整包处理；大包可能短时卡顿。本版保持一致快照和日志事务语义。
