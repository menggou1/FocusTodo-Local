## 旧版依据与问题定位

仅对第 6、7、8、9、10、11、13 项检查不可变 archive/1.9.4，提交 b0ee5e26c133ea273e1634fa52b8a107e1649a69。src/js/main.js 的 AppearanceSettings.darkModeOptions、react-select onControlMouseDown / onDropdownIndicatorMouseDown、PomodoroSettings.getSelectionOptionView / getRingtoneOptionView / changeRingtoneVolume / changeWhiteNoiseVolume 和音频 startVolumeTip 提供代码依据；public/audio/VolumeTip.wav 与当前资源逐字节一致。settings-legacy-reference.cjs 实际启动归档，在随机端口、临时上下文验证顺序、开合、对勾、试听布局、200×10 无边框滑轨和拖动。旧滑块整数步进在本版按用户要求提高为连续精度。

第 12、14、15 项仅依据本次要求和当前实现，不使用旧版行为作设计依据。文件选择 cancel 冒泡被外层 dialog 的 onCancel 当作关闭，已以目标元素判断修复。排序恢复的原始 DOM 采样没有重挂载或重播入场动画，变动为忙碌期间批量 disabled；保留事务保护并消除控件外观跳变。主题此前每次选择均写入，且异步图片尚未解码就替换背景；本版从操作与加载路径修复。

## 验证

新增 settings-regression.cjs 覆盖 15 项相关当前应用交互；settings-feedback.test.cjs 精确检验 100ms、合并输入、播放音量、零音量与销毁清理。浏览器证据使用合成数据与临时上下文；不访问 5500、日常 Profile 或真实数据库。自动化不替代真实音频听感、原生文件对话框人工体验和 Safari 验收，既有实际环境边界统一保留于 [BACKLOG](../BACKLOG.md)。

本地结果：npm test 为 89 通过、1 个既有平台跳过；standalone 单元/合同 65 通过；发布门禁 6 通过。正式/隔离构建、生成检查、完整三引擎 React 业务、历史浏览器回归、Firefox/WebKit 中英文能力降级、正式同 origin 升级与下载备份恢复通过。最终 UI 对照 8 组、任务详情弹窗 4 组、旧版设置专项对照通过；ZIP/tar.gz 校验、空格和中文路径解压、无 npm/Git 启动及 Python 备用启动通过。提交来源 Pages 门禁及远程 CI/正式发布另行核验，不将本地结果写成远程完成。

首轮远程 CI 的 Windows/Linux 全部通过，macOS 在长历史报表的动画组合断言失败；失败截图的结束状态正常，旧采样未保留失败帧，不能仅凭该结果断言产品动画故障。最终视觉专项改为在新建的合成数据副本中预装可控时钟，逐帧推进并保留采样 JSON；继续要求每帧尺寸/DPR/轴线正确、存在中间揭示状态且最终完成。它验证动画逻辑与几何，不作为真实宿主帧耗时已改善的证据。
