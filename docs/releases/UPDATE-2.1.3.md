# FocusTodo 2.1.3 候选版本

[更新记录](../CHANGELOG.md) · [English](../en/releases/UPDATE-2.1.3.md)

开发准备日期为 2026-11-21（Asia/Shanghai）。本报告汇总 2.1.2 发布后进入 `dev` 的改动。作者为 Lexible。

## 日程

- 任务面板展开和收回时与时间轴同步调整宽度。一个按钮在工具栏和面板关闭位置之间移动，同一个加号旋转成叉号。连按可从动画中途反向，减少动态效果模式直接呈现最终状态。
- 计划卡片沿用清单强调色及应用的圆角、字体和明暗配色。按卡片实际宽高显示任务名称和起止时间，窄块优先显示名称，极窄块保留可读内容。提示和详情提供完整信息，周视图复用重叠区间的分栏布局。
- 拖动已有安排时，卡片位于重叠项之上，实时显示起止时间并保留时长。下方拖动柄保持原样，按既有分钟精度和时长限制调整结束时间。松手后继续显示预览，直到事务结果进入快照。写入失败或 expected 校验冲突时，从当前可见位置回到已保存的坐标和尺寸，错误提示浮在页面上。
- 从任务面板拖出时，浮动预览显示任务名称、单次安排时长和放置状态，进入有效时间轴时实时显示预计开始时间。有多次预计番茄时也显示总时长。滚动、缩放和跨午夜安排使用同一坐标换算与分钟吸附，提交沿用预览的时间范围。

## 工作区与计时器

- 普通任务完成后立即显示完成反馈并将原行保留约 250 毫秒。重复任务先旋转图标并显示完成状态，原行约 500 毫秒后移出。完成事务和重复实例在操作时提交，其他页面读取已提交记录。
- 任务和自定义清单拖动时，活动项在上层，其余行平滑让位。松手后从当前可见位置衔接到落点，失败时回到已保存的顺序。系统清单的方向键排序按顺序处理连按及反向输入。计时器右侧组件编辑器复用相同过渡，仅在确认后保存布局。WebKit 下的连续排序按元素已应用的位移接续动画。
- 完成任务报表先显示按优先级和任务顺序排列的任务类别，再显示按各自顺序排列的自定义清单。原始完成数量和归属沿用已提交记录。
- 清单夹的新建任务菜单显示「任务」和直属可见清单。创建事务再次校验目标归属，目标移出、隐藏或删除时回退到「任务」。导出数据窗口的滚动条位于对称圆角内，支持滚轮及键盘滚动。

## 本地安全、预览与 CI

- 正式版及隔离预览的 CSP 允许匹配哈希的内联启动脚本和加载处理程序。Node 和 Python 本地启动器禁止页面嵌入，并校验运行清单、请求目标和服务范围。
- 导出和导入前的安全副本均省略外部联网许可。导入时保留主题和缓存壁纸，之后可在设置中重新授权 Bing 联网。恢复缺失目标设置的旧日志时，回滚原业务数据和本地许可。
- HMR 预览使用 React 开发运行时，修复 `_jsxDEV` 启动错误。浏览器验收使用独立的临时依赖缓存。旧版成就重复恢复在同源数据测试页执行，恢复后重新打开原界面核对奖励，排除页面轮询与维护锁的竞态。
- CI 固定官方 Actions 提交和 Playwright 镜像 OCI 摘要，Linux 在 Bash 中校验镜像版本与摘要。附件复用限制下载及解包大小。首次发布门禁核对版本 Tag、检出提交和远端同版本发布分支 HEAD，维护流程在发布后同步 `main` 与 `dev` 并核验 Pages。
