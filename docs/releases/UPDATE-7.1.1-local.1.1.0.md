## 2. 界面与交互修改

### 2.1 小铃铛更新通知

`js/local-app-ui.js` 的 `renderUpdates()` 在原通知内容前增加版本更新列表，`showUpdate()` 展示标题、日期、完整版本、作者和简短更新项。当前列出本次更新和历史 `7.1.1-patch.1` 阶段。按后续用户要求，已移除窗口底部的详细 Markdown 入口；报告保留在仓库维护文档中。

打开最新详情后才标记更新已读；只打开小铃铛或历史详情不会消除最新更新提示。已读状态保存在 `FocusTodo.releaseRead`，刷新及其他标签页能同步；如果存储写入失败，提示未能保存已读状态。

原任务提醒的 `getItems()` 保留。旧通知面板高度固定为 300px，加入更新条目后任务提醒会溢出；本次增加专用 class 和自适应高度、视口最大高度及滚动，验收检查提醒区域仍在面板内。

小铃铛支持 Enter/Space 打开。详情对话框限制 Tab 焦点范围，支持 Escape/关闭按钮，并恢复打开前焦点；打开期间阻止旧应用快捷键影响底层计时器。

### 2.2 关于页与 GitHub 图标

关于页显示完整版本、官方 7.1.1、本地 1.1.0、作者 Lexible 和日期，删除评分行与旧更新说明。仓库入口为 `img/github.svg` 图标，无需额外图标库或远程图片。

图标链接为 **https://github.com/menggou1/FocusTodo-Local**，来自 `git config remote.Focustodo-local.url`；标题显示地址，提供可访问名称，使用 `target="_blank"` 和 `rel="noopener noreferrer"`。点击阻止旧全局事件误拦截链接。实际弹出新页和地址已经验收，测试用本地响应替代 GitHub 联网访问。

### 2.3 删除数据

设置 → 账号 → 删除数据，打开本地确认窗口，不再进入密码/用户名校验或后端删除接口。打开后以 `performance.now()` 单调时钟记录 5 秒截止时间，按钮每 100ms 更新倒计时；点击处理也检查截止时间，不能靠提前触发点击跳过冷却。

取消或 Escape 关闭会清理计时器，数据保持原样；重新打开重新等待 5 秒。确认后禁用重复确认和取消，等待 `FocusLocalReady`，调用 `FocusLocalData.reset()`，完成后才刷新。失败时不刷新，窗口显示错误并恢复重试/取消；同一窗口已完成冷却后的失败重试不再另等 5 秒。

数据服务复用现有完整备份、IndexedDB 替换事务及设置恢复日志：删除前发起 JSON 备份下载；清空任务、专注记录和会话，重置用户设置并建立本地默认身份；保留必要的服务器配置、语言等兼容项。备份元信息使用当前完整版本。下载链接增加事件传播处理，避免原全局点击逻辑阻止下载。

浏览器只提供下载发起行为，程序没有确认用户已把文件实际保存到磁盘的能力。测试验证了完整 JSON 下载及内容；真实浏览器若阻止下载，仍需关注下载提示，不能把“发起备份”解释为已确认永久落盘。

删除验收发现旧项目的排队刷新会在清空后读取不存在的项目，抛出 `undefined.type`。在旧模块 863 的 `checkProject()` 入口检查项目是否存在和维护状态，让失效刷新退出；没有改变正常清单选择行为。

## 3. 版本规范与维护整理

`release.json` 集中维护官方版本、本地版本、作者、日期、remote 名及更新内容。`scripts/build-release.cjs` 生成浏览器元信息并同步包版本、页面标题和缓存参数。版本详情、关于页、备份和服务器输出保持一致，减少多处手改遗漏。

完整规范见[维护指南中的版本与发布](../MAINTENANCE.md#4-版本与发布)：官方前缀固定为 7.1.1；本地修复递增最后一位，兼容功能递增中间一位，不兼容本地改变递增第一位。当时 1.1.0 承接历史 patch.1 阶段；历史报告原名保留。数据库版本仍为 v3，旧设置 `Version='6.5'` 保留其兼容用途。

本次低风险整理：

1. 将新增更新/关于/删除交互放入独立 `local-app-ui.js`，统一对话框、DOM 文本创建、错误显示和关闭清理；不把新业务继续塞进 `patch.js` 的轮询。
2. 移除已失效的关于页 MutationObserver 注入和删除密码警告轮询，避免重复行、过期版本及对其他密码框的误匹配。
3. 从两个接入脚本抽取 `scripts/lib/bundle-editor.cjs`：统一 AST 查找、唯一匹配检查、编辑重叠检查、写入前语法解析；重复运行保持 bundle 内容不变。
4. `local-ui.css` 统一为逐项分行格式；纯格式整理保持去除空白后的内容一致，新增样式有明确 class 范围。
5. 清理新模块中的硬编码版本，更新说明和 README/架构文档同步现状。

没有全局转换 var/let/const、重命名压缩变量、重写所有异步代码、升级依赖或数据库，也没有恢复完整组件源码。上述工作缺乏完整源码及全面行为覆盖，不能仅凭格式统一判定安全。
