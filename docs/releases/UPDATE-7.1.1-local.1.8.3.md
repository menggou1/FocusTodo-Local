## 问题与修复

基于 56df8eb 的外部审查修补包，校验全部文件摘要后应用六类修复：

- 导入前验证计时会话、日期范围、安全整数、累计秒数与历史序号，损坏输入不会进入维护或覆盖事务。
- 在同一 IndexedDB 写事务中比较日程原快照；本地拖动、删除和旧详情编辑携带原记录，拒绝过期覆盖与软删除复活。
- 被拦截的 XHR 取消或重开后不再完成旧响应，补齐事件顺序、响应类型与静态常量。
- 提醒和森林奖励使用循环与归约，避免海量记录展开为函数参数时溢出。
- 中断休息的恢复视图继续使用休息阶段的时长和已过时间。
- Python 备用服务器校验 Host，并发送 no-store/nosniff，避免复用旧缓存。

额外修复阳光动画结束后闪回原位：动画填充取消时，异步列表查询与 React 移除之间可能跨越多个绘制帧。已成功提交的节点先隐藏再释放动画；失败节点完成动画后恢复可重试。一键收取和单项收取共用此逻辑，持久化与奖励去重规则保持不变。

任务提醒的每行统一保留 16px 水平边距，日期独立成行，使用次级文字色与一致行间距。长标题自然换行，避免旧样式固定高度造成重叠；样式限定在提醒列表内。

数据库仍为 PomodoroDB6 v3；应用版本为 7.1.1-local.1.8.3，Tag 为 1.8.3。
