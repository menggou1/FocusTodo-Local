# 7.1.1-local.1.7.6 — 教程、文档与启动验收改进

## 更新内容

- 延续 [1.7.4 候选版](UPDATE-7.1.1-local.1.7.4.md)的中英文图文教程、关于页入口、README 清理及历史报告归档，保留旧地址链接。
- 启动验收仍使用真实同源服务器和外网阻断，仅拦截外部请求及需要故障注入的请求，避免为每个同源请求增加一次自动化协议转发；保持资源并行和原有断言。
- 新增 `local-app-ui.js` 加载失败后显示重试、重新加载成功且本地设置保留的受控检查。启动失败证据在释放受阻资源前保存。

## 背景与验证

[1.7.5 候选报告](UPDATE-7.1.1-local.1.7.5.md)记录 Windows 关键脚本 `net::ERR_NO_BUFFER_SPACE` 失败及未完成的发布。此结果不能推断 1.7.4 超时的根因；资源耗尽的具体来源尚待定位，追踪在[统一待办](../BACKLOG.md)。1.7.4 和 1.7.5 未创建标签或 Release。跨平台验证及发布结果以 GitHub Actions 为准。

本地执行版本生成、语法和发布元数据检查，以及隔离浏览器启动验收；18 项启动场景通过，包含模拟关键模块失败和用户重试。
