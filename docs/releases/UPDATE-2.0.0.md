# FocusTodo 2.0.0

更新日期：2026-11-16。作者：Lexible。[English](../en/releases/UPDATE-2.0.0.md) · [测试](../TESTING.md)

## 架构与兼容

从完整React/TypeScript源码构建独立应用；正式入口、便携包及Pages构建采用同一资源manifest，旧主包仅保留作兼容和UI基准。正式适配器继续使用PomodoroDB6 v3及旧设置键，隔离预览保持独立命名空间。任务/记录ID、未知兼容字段、旧JSON/Gzip、计时恢复和维护日志继续由显式服务维护。独立应用版本2.0.0与来源7.1.1、DB/备份版本分别管理。

## 本轮功能修复

- 番茄时间轴先提交最终画布尺寸、坐标轴与行高，再从下往上揭示记录，移除占位树替换及绘制后高度更新。
- 已完成页恢复记录/任务卡片背景及中性完成图标，按完成日和结束日分组，保留旧日期、行距、统计与交互。
- 工作中的关联任务使用旧版秒表，暂停/停止/完成按状态恢复图标。
- 森林开关控制顶部入口，订阅已提交设置，重启与重新启用保持一致。
