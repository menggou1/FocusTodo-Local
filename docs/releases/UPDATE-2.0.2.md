## 应用行为

本版包含此前 15 项设置、头像、主题、音量与文件取消修复，逐项实现与验证依据保留于 [2.0.1 候选记录](UPDATE-2.0.1.md)。它们从 dev 线性保留；本轮没有重做已完成的功能。简体中文标题继续读取统一版本源，显示专注清单2.0.2。

## macOS 视觉回归根因

[发布分支 CI #137](https://github.com/menggou1/FocusTodo-Local/actions/runs/44087392129) 的 macOS / Node 24 在重复任务删除弹窗比较失败：旧版 y=268.71875，新版 y=258.71875，相差 10px；紧接着保存的截图已回到 y=268.71875 的正常尺寸。新弹窗首次使用此前未请求的 Noto Sans SC 700 字重，font-display:swap 允许加载期间回退。启动时等待过的 document.fonts.ready 无法覆盖后续新请求，固定等待 300ms 也不构成字体加载完成条件。

几何取样先触发布局以确定当前文字需求，再等待当前 document.fonts.ready，然后读取同一批尺寸和样式。应用动画、布局、字体、1px 像素阈值及八组语言/主题/窗口宽度均不改变。新增 ui-font-readiness.cjs 挂起真实打包粗体响应，要求采样在加载时保持等待，释放后严格对照不可变 1.9.4；该断言在旧采样实现下失败。

## CI 与发布

dev 完整执行 Windows/macOS/Linux × Node 22/24。发布分支、main 和 Tag 仅复用确切 SHA 的成功作业与原始已测附件，同时检查摘要、有效期、测试时序、更新失败记录，并与新构建逐文件比较；缺证据时全测，失败不得视为通过。每次保留构建、版本、来源、解压启动和独立证据门禁。

测试只使用随机隔离端口、临时浏览器与合成数据。正式 Tag 指向通过检查的 main 最终提交；正式附件、Pages 来源与清理按维护指南核验。执行状态及人工/真实系统边界只维护于 [BACKLOG](../BACKLOG.md)。

本轮本地验证：类型检查、正式/隔离构建、82 份文档链接检查、89 项单元（一个既有平台跳过）、66 项 standalone 合同、9 项 CI 复用策略、6 项发布门禁、冷字体正反例、最终 UI 八组及详情弹窗四组通过。便携 ZIP/tar.gz 校验、空格/中文路径解压、无 npm/Git 启动和 Python 备用启动通过。云端和正式发布结果以确切提交的 Actions/Release 记录为准。
