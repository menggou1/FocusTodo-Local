# 7.1.1-local.1.9.1 更新报告

[更新记录](../CHANGELOG.md) · [维护指南](../MAINTENANCE.md) · [统一待办](../BACKLOG.md)

日期：2026-11-07。作者：Lexible。

小窗改为官方 Windows 商店版 7.2.2.0 的紧凑浮动计时条：58px 行高、40px 圆形计时盘、分钟显示、任务标题和 26px 图标控制。直接复用现有 FloatTimer 渲染组件和官方小窗图标、控件样式，背景跟随当前主题；暂停时显示继续和停止，休息时使用结束休息图标。独立窗口的最小实际尺寸由浏览器决定。

页内浮动计时条和展开计时器的原角落按钮移动至右上角，左上角新增官方小窗口按钮。只有这个专用入口会请求 Document Picture-in-Picture；原展开、收起与双击只在页面内切换。无 API 或请求失败时仍提示并回退页内计时器。独立小窗内左上角返回、右上角关闭均释放视图并保留计时。

样式和四个图标取自本机已安装的官方 7.2.2.0 包 `FocusToDo/WebContent`，不是仓库原有的 7.2.2 源码。计时命令继续走同一适配器，复用主页面 tick、会话和跨标签广播；小窗关闭时卸载 React 视图，不产生第二套数据库或计时循环。数据库保持 v3，旧备份、主题和偏好兼容。

专项覆盖专用入口、角落位置、普通缩放/双击不请求小窗、缺失 API/拒绝回退、原生小窗的 58px 布局及开始/暂停/停止/跨标签同步。其余未完成的真实环境验收仅在 BACKLOG 维护。
