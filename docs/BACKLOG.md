## 工程与功能

| 编号 | 优先级 | 未完成工作 | 范围与约束 |
|---|---|---|---|
| E01 | P1 | 主题图片迁入 IndexedDB Blob/资源表 | 当前原图、缩略图仍是 localStorage data URL。先复制和校验，再切换引用、清理旧数据；保存可恢复迁移状态并兼容旧备份。数据库升级时说明回退限制，不能删库回退。 |
| E02 | P1 | 主题跨标签并发编辑归属 | 单操作设置写入回滚、启动恢复与严格跨页串行不是同一保证。同步 localStorage 没有跨进程 CAS；须为并发主题编辑设计归属和冲突处理，不能用超时冒充安全接管。现有导入/重置维护锁不替代主题编辑锁。 |
| E03 | P1 | 独立二进制资源备份格式 | 评估 ZIP + JSON + 资源清单、内容摘要去重及缩略图重建，主题通过资源 ID 引用。默认保留原图字节；覆盖前检查资源完整性、引用、版本及解压上限。Gzip 已交付，不把 ZIP 当作已有功能。 |
