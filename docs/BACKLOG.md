### E11 迷你窗口实施方法

在 `local-timer-ui.js` 增加能力检测与用户手势入口；支持 Document Picture-in-Picture 时创建只读显示和开始/暂停/停止控制，命令仍由现有计时适配器提交。迷你窗口不得另开一个 tick 写入循环、数据库名称或业务会话；主窗口/迷你窗口关闭时解绑订阅、释放样式与引用。无此 API 时沿用页内浮动计时器，并明确浏览器能力。先在支持的 Chromium 上验证开关窗口、休息切换、后台恢复、多标签拥有权和关闭清理，再在 Firefox/Safari 验证回退。若采用 `window.open`，还需验证弹窗被拦截及同源失联，不承诺原生置顶/移动窗口权限。

### V03 日程与报表后续验收方法

使用独立数据生成已知 23:50–00:20、含暂停和不同任务/子任务的记录，分别查看日程、历史、日报/周报，再导出恢复比较记录 ID、秒数、归属和图表值。时区至少覆盖 Asia/Shanghai 与有夏令时的 America/New_York 切换日；必要时修正 `createCalendarDayEvent`、`local-calendar.js` 的日边界和原报表分片，不通过重写历史时间戳修饰结果。当前自动化的合成时间与事务故障覆盖不能代替这些真实场景。
