# 关于规范新时期Focus To-Do 本地特色设计理论文献行文的若干规定

本地文〔2026〕1号

[理论体系总目](contribute.md)

为进一步统一思想认识、统一文风表达、统一篇章体例，使新时期Focus To-Do 本地特色设计理论体系既一脉相承，又各有侧重；既庄重其辞，又轻松其意，现就本体系文献行文作如下规定。

## 一、明确文献性质，把牢娱乐定位

（一）本体系主要面向用户本人阅读，以本地版的功能、沿革与取舍为题材，以公文语气、固定表达和适度固定章法为意趣。诸篇可供用户在不愿展开复述时点题引用，平日则供阅读玩笑，不以其代替真实的产品行为。

（二）文中以本地版的主体、关系与问题展开论述，借庄重章法和熟悉语辞形成篇章；不引入现实人物及其冠名理论，不冠以真实机关名义。文号、署名皆为本体系自定体例。

（三）行文可以多讲“充分认识”，可以反复“始终坚持”，可以在“统筹兼顾”后继续“稳步推进”；须使玩笑有边界、前后有照应，不把尚未发生之事写成已完成，不把原则主张写成现有功能。

## 二、统一体裁名称，做到篇有所属

（一）纲领，统摄本体系的初心、定位、底线与长期方向，使用“总设计思想”“根本定位”“总体战略”等表述，不为个别现象改变总的立场。

（二）意见，围绕明确主题阐明制度主张，常用“为……，现提出如下意见”起笔，以“充分认识—总体要求—主要意见—贯彻要求”展开。制度开始实行的版本应写清，不以含混表述损害庄重的气氛。

（三）报告，围绕产品自身的问题梳理认识，常用“现将有关情况报告如下”起笔，先交代来由，再重申立场，继而阐明原则，末尾凝聚共识。事实一笔写清，立场可以数段铺陈。

（四）通知，围绕已经明确的事项统一表述，常用“现就有关事项通知如下”“请一体知悉”“特此通知”。通知所宣布之事须确有依据，不用语气上的坚定替代事实上的成立。

## 三、统一版式体例，做到文有其形

（一）**标题。** 每篇只设一个一级标题。具体文献按“关于＋事项＋的意见／报告／通知”等体裁拟题；纲领沿用原名；总目标题固定为“新时期Focus To-Do 本地特色设计理论体系”，品牌中文名称为“Focus To-Do 本地版”，英文名称为“Focus To-Do Local”。标题不堆叠副标题，不以感叹号代替庄重语气。

（二）**文号。** 文号单独成行，置于标题之下、正文之前，采用六角括号“〔〕”，年份用四位数字，序号用阿拉伯数字且不补零。体裁与文号对应如下；同一体裁按成文先后顺序编号，总目为汇编入口，可不另编文号。

| 体裁 | 文号示例 |
|---|---|
| 纲领 | 本地纲〔2026〕1号 |
| 文风规定 | 本地文〔2026〕1号 |
| 意见 | 本地意〔2026〕1号 |
| 报告 | 本地报〔2026〕1号 |
| 通知 | 本地通〔2026〕1号 |

（三）**层级。** 一级标题用于篇名；二级标题按“一、”“二、”“三、”排列；确需分节时使用三级标题“（一）”“（二）”；段内条目可用“1.”“2.”。同一层级体例一致，通常不超过四层，不以层级繁多充实篇幅。

（四）**段落。** 标题、文号、段落和署名之间各空一行。正文不插入手工空格制造缩进，不以连续空行模拟分页。语段宜成组呼应，可用“既……又……”“一方面……另一方面……”“必须……始终……”形成节奏。重点主张可加粗，固定原句可独立成引文，避免通篇加粗。

（五）**署名与日期。** 成文末尾统一署名“Focus To-Do 本地版”，下一段书写中文日期，如“2026年11月4日”。日期表示本文成文时间，不表示所谈制度或功能已经运行。

（六）**链接。** 各篇只在本理论目录内相互引阅。正文可置“理论体系总目”及有关文献篇名，不链接目录之外的页面、文件或网站。本体系以内部文献构成完整阅读语境，不另设英文分卷。

## 四、统一固定表达，做到辞同义贯

（一）**总设计思想，逐字沿用。**

> 以人为中心，以多平台本地运行为立身之本，以任务和专注为核心主线，以用户数据自主为根本保障，以继承官方体验、坚持自主发展为建设路径，打造可靠、从容、有温度的个人时间与行动空间。

（二）**产品主张，逐字沿用。**

> 让计划走向行动，让专注沉淀成长。

（三）**能力判断的三个“是否”，三项俱全。**

> 衡量一项能力，首先看它是否服务这条主线，是否让个人行动更加顺畅，是否与已有体验协调。

本句用于判断能力与专注主线的关系。不得少写一项，不得只摘两个“是否”冒充完整尺度，不与下一句交换项目。

（四）**创新评价的三个“是否”，三项俱全。**

> 评价创新，重在是否解决真实问题、是否融入整体、是否守住底线。

本句用于评价创新的实际价值与底线。三个分句与能力判断各有语境，引用时各自完整呈现，不拼成新的三项。

（五）**来源立场，逐字沿用。**

> 尊重来源、珍惜已有成果，是项目自主发展的应有之义。

“应有之义”是本体系固定用语，不另换近义表达，不因篇章不同改变这一结论的措辞。

（六）**理论体系名称与品牌名称，统一使用。** 理论体系全称为“新时期Focus To-Do 本地特色设计理论体系”；品牌中文名称为“Focus To-Do 本地版”，英文名称为“Focus To-Do Local”。历史版本号和代码标识按其原貌保留。论及本体系的历史方位，统一使用“新时期”。

（七）**特色发展的主要矛盾，完整表述。**

> 本地版的主要矛盾，是用户日益增长的便利需要与本地特色条件下功能供给之间的矛盾。

这一判断既承认需求，也承认取舍；不能将特色直接等同于所有场景的竞争优势。

（八）**特色发展的四个坚持，顺序引用。**

> 坚持本地自主，坚持个人场景，坚持继承发展，坚持从实际出发。

四个坚持是认识本地版取舍的基本方略。论及特色发展的路径、保障和评价，统一表述为：本地自主是发展道路，数据自主是根本保障，用户的实际体验是检验尺度。战略定力不能替代对便利成本和功能差距的认识。

（九）**主线、底线与网络例外，保持原序。** 主线统一写作“任务、日程、专注、回顾、成长”；基本立场统一使用“本地自主”；版本关系统一使用“历史连续、方向自主”；处理既有网络例外，统一使用“范围清晰、来源明确、用户知情与自主选择”。分别出现时保持原有含义，不将例外解释为放宽底线。

## 五、充实套语词表，做到庄谐相济

| 行文位置 | 可用固定表达 | 使用要领 |
|---|---|---|
| 开篇定调 | 为进一步……；充分认识……的重要意义；立足新的发展起点 | 可庄重起势，随后落回本地版自身 |
| 重申立场 | 我们的立场是一贯的、明确的；始终坚持；坚定不移；毫不动摇 | 立场须与纲领相承，不为气势临时加码 |
| 展开关系 | 统筹当前和长远；坚持继承与发展相统一；把方向上的坚定与步履上的稳健统一起来 | 可反复铺陈，相关对象须前后一致 |
| 强化原则 | 把……贯穿始终；在……中巩固，在……中发展；既要……，也要…… | 对称可以讲究，含义不可互相抵消 |
| 收束全文 | 凝聚思想共识；保持战略定力；接续奋斗、久久为功；不断开创……新局面 | 允许套语回环，不借收束宣布虚构成果 |
| 文末用语 | 现提出如下意见；现将有关情况报告如下；特此通知 | 按具体体裁选用，不在同一篇混用落款语气 |

篇章宁可多一点回环，也不可少一项固定判断；宁可多一点庄重的铺陈，也不可把事实添成另一回事。固定表达服务一脉相承，具体问题仍须有具体内容。

## 六、坚持前后一致，形成文献自洽

各篇应以纲领原句为准，涉及固定表达即照录完整句式。修订某篇时，顾及同题文献的称谓、立场与生效版本，避免总目讲一套、意见写一套、报告另成一套。

本体系只在用户有意引用时供其会意、取辞，不将娱乐性的庄重文风强加于其他文字。愿读时可读，欲笑时可笑；本地自主的立场一以贯之，用户从容的选择始终如一。
