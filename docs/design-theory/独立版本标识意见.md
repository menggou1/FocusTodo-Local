# 关于建立 Focus To-Do 本地版独立版本标识制度的意见

本地意〔2026〕1号

[理论体系总目](contribute.md) · [新时期设计纲领](Focus-To-Do-本地版新时期设计纲领.md)

为深入贯彻新时期设计纲领，进一步明确本地版的发展主体地位，统筹历史连续与方向自主，使版本表达同本地版的建设进程相适应，现就建立独立版本标识制度提出如下意见。

## 一、充分认识独立版本标识的重要意义

版本之名，承载发展之实，亦昭示前进之向。本地版从官方成果中走来，在本地建设中成长；既有自身积累，也有自身取舍。发展到了新的阶段，就应当形成与自身定位相适应、与自身节奏相协调、与自身使命相贯通的版本坐标。

确立独立版本标识，是把本地版的事情放在本地版的发展脉络中认识，是在尊重来路中把握前路，在保持连续中彰显自主。既不以追随外部版本为成绩，也不以割断历史来源显独立，使名称与方向相称，使阶段与积累相承。

## 二、明确制度安排，稳步形成独立坐标

独立版本标识制度**自 2.0.0 起实行**。本地版对外采用独立三段式版本，以自身的主版本、功能版本和修复版本表达发展阶段，不再将官方 7.1.1 作为当前版本名称的固定前缀。

1.8.0 使用 `7.1.1-local.1.8.0`，独立标识自 2.0.0 起实行。制度的起点已经明确，阶段的衔接必须稳健；不能因方向已定而混淆当前标识，也不能因当前沿用旧制而含混未来制度。

独立版本制度之下，主版本体现阶段性发展，功能版本体现兼容能力的持续建设，修复版本体现既有体验的品质完善。版本是发展的表达，不是攀比的尺度；是自身节奏的记录，不是追随外部数字的凭据。

## 三、坚持历史连续，正确把握继承与发展

尊重来源、珍惜已有成果，是项目自主发展的应有之义。

原有作者信息、来源与许可得到尊重，既有版本名称和历史含义得到保留，用户长期形成的熟悉体验与个人积累得到珍惜。版本可以独立，历史不可抹去；方向可以自主，传承不可轻忽。要把对既有成果的尊重，同对本地需要的担当统一起来。

独立坐标不意味着以更名代替建设，也不意味着以新名称冲淡本地底线。多平台本地运行、个人数据自主、熟悉的专注体验，应当贯穿版本演进全过程，在新的版本表达中得到更加清楚的体现。

## 四、坚持统一尺度，始终服务专注主线

衡量一项能力，首先看它是否服务这条主线，是否让个人行动更加顺畅，是否与已有体验协调。

评价创新，重在是否解决真实问题、是否融入整体、是否守住底线。

上述尺度，既适用于功能建设，也适用于版本表达。不能只重名称的新意，不重体验的连续；不能只讲阶段的跨越，不讲用户积累的延续。要让版本独立同本地自主相互支撑，让发展叙事同用户感受相互印证。

## 五、保持战略定力，凝聚自主发展共识

独立版本制度的实行，是本地版走自身道路的阶段性表达。要坚持从自身定位出发，以自身需要确定取舍，以自身积累赢得连续，在稳中求进中巩固方向，在守正传承中深化发展。

我们对历史的尊重是一贯的，对自主的坚持是明确的，对用户积累的珍惜是长期的。以 2.0.0 为新的版本起点，把名字写在自己的坐标上，把初心留在每一次从容的专注里，接续奋斗、久久为功。
