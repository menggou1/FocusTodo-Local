# 新时期本地特色FOCUSTODO设计理论体系

新时期本地特色 FOCUSTODO 设计理论体系，是围绕本地版自身定位、历史沿革和发展方向形成的娱乐性文献汇编。文风从严肃处落笔，阅读从轻松处会意；所谈皆为本地版之事，所指皆为产品自身，无现实对象的指代。

让理论有体系，让表达有章法，让专注有方向。用户平日不必事事展开、句句复述，有意沿用这里的立场与口吻时，点明篇名，便可会其意、循其辞。除此之外，诸篇自成一隅，供闲时翻阅、茶余会心。

## 二、以固定表达凝聚共识，以完整表述保持连贯

判断一项能力，完整表述为：

> 衡量一项能力，首先看它是否服务这条主线，是否让个人行动更加顺畅，是否与已有体验协调。

评价创新，完整表述为：

> 评价创新，重在是否解决真实问题、是否融入整体、是否守住底线。

论及来源，统一沿用：

> 尊重来源、珍惜已有成果，是项目自主发展的应有之义。

三项俱全，方成其意；字句相承，方见其脉。前一组三项立足能力与专注主线，后一组三项立足创新与底线尺度，各循其义，不相混用。更多固定表达及行文约定，载于本体系文风规范。

## 三、以从容之心读严肃之文，以会心之意守本地之本

凡此诸篇，皆以娱乐为意趣，以本地版为题材。空话可以成段，套话可以成篇，立场须前后一致，事实须不增不减。既可在坚定不移中会心一笑，也可在久久为功中想起手头尚未开始的那个番茄钟。

让计划走向行动，让专注沉淀成长。
