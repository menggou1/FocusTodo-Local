# 关于正确认识本地特色与发展竞争关系的意见

本地意〔2026〕2号

[理论体系总目](contribute.md) · [新时期设计纲领](Focus-To-Do-本地版新时期设计纲领.md)

为深化对本地特色的认识，统筹自主选择与使用便利，进一步统一对发展方向和竞争处境的理解，现提出如下意见。

## 一、准确把握特色发展的主要矛盾

本地版的主要矛盾，是用户日益增长的便利需要与本地特色条件下功能供给之间的矛盾。

本地特色形成于对个人场景、本地运行和数据自主的坚持，也体现为对云端协作、自动同步等方向的取舍。其他产品提供的便利可能更适合另一些用户；本地版所选择的边界，既塑造自身面貌，也限制可以提供的便利。特色越鲜明，越要认识到特色有其适用范围。

## 二、坚持特色发展的基本方略

坚持本地自主，坚持个人场景，坚持继承发展，坚持从实际出发。

本地自主是发展道路，数据自主是根本保障，用户的实际体验是检验尺度。要把方向上的自信建立在对条件的清醒认识之上，把对自身道路的坚持同对其他选择的尊重统一起来。

坚持本地自主，就要正视用户自行备份和迁移所需付出的精力；坚持个人场景，就要承认协作需求可能转向其他产品；坚持继承发展，就要认真辨别哪些经验适合本地条件；坚持从实际出发，就要允许用户根据自己的需要作出不同选择。

## 三、统筹特色保持与竞争认识

发展有特色，不意味着每一项比较都有优势。对同类产品拥有而本地版没有的能力，既不能不加区分地追求齐全，也不能仅凭一项定性就免去解释取舍的责任。该说明的不便要说明，该承认的差距要承认，该由用户决定的选择要交给用户。

衡量一项能力，首先看它是否服务这条主线，是否让个人行动更加顺畅，是否与已有体验协调。

评价创新，重在是否解决真实问题、是否融入整体、是否守住底线。

两个尺度既用于说明选择，也用于审视选择。不能因为某项能力没有进入范围，就认定其没有价值；不能因为某项安排符合既定方向，就认定其已足够方便。

## 四、保持战略定力，增进对实际处境的认识

要善于从长期方向中认识眼前取舍，也要善于从具体体验中检验长期表述。对用户而言，特色需要通过实际使用体现；对文献而言，方向需要通过反复阐述得到进一步明确。

坚持把可供选择的范围讲清楚，把选择所需承担的成本讲清楚，把尚待改善之处讲清楚。既保持发展的定力，也保持认识问题的耐心，使特色始终成为特色，使方向始终具有方向。
