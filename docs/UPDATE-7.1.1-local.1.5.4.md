# 7.1.1-local.1.5.4 — 系统清单排序与用户名存储修复

发布日期：2026-10-28。

- 系统清单使用界面内指针拖动及浮动预览，不再向浏览器交付文本拖动，也避开原版拖拽框架的接管。禁放区域保留灰显，主动移动行在排序动画中置于其他行上方。
- 管理界面移除自定义清单的拖动手柄、拖动排序和键盘排序；自定义清单及清单夹继续由主界面原版功能管理。
- 新增“恢复系统清单默认排序”，复用初始化的默认值，只改系统清单的顺序字段，保留隐藏状态、其他设置和自定义清单数据。
- 用户名继续使用兼容旧组件的 localStorage `cookie.NAME` 键；清理浏览器里不再被读取的 `NAME` Cookie，旧写入入口也不再创建它。旧控制台改名调试函数已经移除，无需再次保留或重建。

本次按用户要求收窄本地验收范围：语法、发布元信息，以及直接相关的清单和本地资料场景。不重复执行无关的本地全量、性能或人工环境验收；发行沿用仓库现有自动 CI。

候选 `1.5.3` 标签保留。其主分支六项 CI 与线上部署成功；标签 macOS 的头像验收两次在刷新后打开设置时超时。`1.5.4` 仅为验收辅助函数补上首屏就绪等待，保留本轮全部产品功能，以新标签完成发行。
