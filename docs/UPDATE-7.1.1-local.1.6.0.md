# 7.1.1-local.1.6.0 — 日程增强与任务快捷日期

日期：2026-10-28（Asia/Shanghai）。本报告记录当前工作树的本地实现与验证；本轮仅本地提交，没有合入 main、推送、创建发布标签、Release 或部署 Pages。

## 完成的功能

| 功能 | 实现后的行为 |
|---|---|
| 日历入口 | 恢复原先被本地旧包过滤的系统日历清单，沿用清单隐藏和排序设置；已有任务列表、日历详情与时间轴继续使用。 |
| 双击快速创建 | 双击已安排列的空白处，显示预览并打开添加任务窗口，默认使用当前工作时长。可填写名称、预计番茄数、每个番茄分钟数和实际所属清单。 |
| 拖选快速创建 | 在已安排列向上或向下拖选，以较早端点为开始时间，按分钟生成预览；已完成列不提供创建入口。取消或 Escape 清理预览，不写任务和安排。 |
| 保存规则 | 任务截止日为开始日期的当天结束；预计数保留实际填写值，最多安排前 5 个番茄，每段之间使用短休息间隔。每段 1–180 分钟；预计数 1–99。遵循顶部添加新任务设置。 |
| 原子创建 | 任务与全部安排在同一个 IndexedDB 事务中提交；验证清单仍存在且可存任务，检测导入/重置维护标记。中途写入失败时整体回滚，窗口保留输入供重试；保存期间禁用重复提交与取消。 |
| 从安排开始专注 | 安排块带播放按钮，读取最新任务/子任务，检查完成与删除状态，交由现有本地计时器启动。没有新建独立计时会话或修改专注记录门槛。已完成块没有播放入口。 |
| 重叠布局 | 同一列内发生重叠的安排和完成记录分列显示，独立计算左右两列；相邻不重叠时间可复用宽度。短记录按最小可点击高度参与布局；越过午夜的时间块只裁剪显示，不重写原始时间戳。 |
| 颜色与文字 | 沿用所属清单的颜色主题、安排虚线和完成实线。短块同行显示标题与时长，长块按高度截断标题；完整名称与时间范围可通过悬停提示查看，支持键盘打开详情。 |
| 详情与跨页刷新 | 安排修改关联后清理任务/清单缓存并重载；完成记录修改时间、时长或关联后更新当前详情和块文字。通过已有 BroadcastChannel 通道发送提交后的日历变更；其他页同步重载，页面重新获得焦点时也重载。计时器新记录会刷新日历。 |
| 保留既有操作 | 保留任务拖入、移动、缩放、右键复制/删除、安排与完成记录各自的详情。安排写入改用本地事务服务；移动/缩放失败后从已提交数据重载，复制/删除失败显示提示。关闭详情不会自动删除用户已有的无关联安排。 |
| 日期与当前时间 | 日期按钮打开日期选择窗口，上一天/下一天/今天沿用原操作；同一标签页保留时间轴滚动位置，日期切换和刷新后恢复。当前时间指示每分钟刷新，卸载时清理定时器及鼠标监听。 |
| 下周到期 | 任务右键菜单新增快捷项，按当前日期加 7 个自然日并取那天结束时间，含跨月/跨年处理。不是下个自然周周末。 |
| 语言和外观 | 新界面提供中英文，复用既有主题颜色、字体和用户内容；任务名、清单名不翻译。快速创建窗口支持窄窗口、焦点循环、Escape，并隔离底层快捷键。 |

## 本地版边界与版本选择

官方 7.2.2 的兼容日程能力在现有 7.1.1 本地基础上实现，没有整体替换官方主包。账号同步、网络连接诊断、在线小组/排行、服务器积分和遥测没有接入；浏览器没有 Windows 原生窗口宿主。保留现有页内浮动计时器。专注森林入口和后台奖励初始化本轮保持停用，其已确认后续工作和实现方法统一记录在[未完成事项](BACKLOG.md)。调查资料保存在项目外，不进入本次提交或压缩包。

这是兼容功能增加，完整版本为 `7.1.1-local.1.6.0`。数据库仍是 `PomodoroDB6` v3，业务备份仍用已有格式，已有任务、记录和偏好不需要迁移，因此不满足维护指南中“本地不兼容改变”才使用 `2.0.0` 的条件。回退可恢复旧程序文件并沿用同一地址；新建的任务和安排仍是旧版认识的数据类型。旧本地版隐藏的日历入口不影响备份保存安排。

## 维护落点

- `js/local-calendar.js` 保存交互、布局和生命周期；`scripts/revise-calendar-integration.cjs` 通过模块 AST 检查接入日历控制器、时间轴、安排存储与任务菜单。保留原本地修改，脚本重复运行结果稳定。
- `js/local-data.js` 增加任务与安排原子事务、安排写入和提交后通知；沿用本地数据维护日志与串行队列，不增加网络来源或数据库版本。
- `release.json` 是版本和中英文更新条目的人工入口；构建生成发布信息、HTML 和英文报告。
