## 可运行预览

仓库目录：`D:\document\projects\Focustodo-dev`，分支：`refactor/standalone-app`。

```powershell
Set-Location D:\document\projects\Focustodo-dev
# 已安装依赖的当前工作区可直接从构建开始；新克隆先执行 npm ci
npm run build:standalone
npm run preview:review
```

打开 **http://127.0.0.1:5512/**。使用同一主机名、端口和浏览器 Profile，刷新/重启后仍保留审查数据。停止时在启动窗口按 `Ctrl+C`。5512 被占用时不要结束未知进程；可用 `npm run start:standalone` 取得随机地址，或 `node scripts/standalone-server.cjs --port 5513`。不同端口有独立数据；5512 的数据不会出现在随机端口。专用服务禁止使用正式应用的 5500 端口。

预览仅访问 `FocusTodoStandalone.PomodoroDB6` v3、独立锁库及 `FocusTodoStandalone.data.` 偏好。默认不访问外网，不接触正式 5500 来源的数据。不需要账号；云同步、小组和在线排名沿用路线的排除范围。

若从工程包运行，执行 `npm run package:standalone`，完整解压 `dist/standalone/FocusTodo-standalone-prototype.zip` 或 `.tar.gz`，在包目录运行 `node start.cjs`，打开打印的随机地址；无需 npm 依赖。包名仍为 prototype，属于工程审查产物，不是 2.0.0 Release。

## 有数据的核查方式

[演示备份](../acceptance/2.0.0-dr/demo.json)由 `node tests/fixtures/create-review-demo.cjs` 生成；包含标有“演示”的清单、文件夹、标签、8 个任务、3 个子任务、28 段历史及 3 个日程，时间基于生成日期。只有合成内容，没有真实备份、用户头像或私人数据库。工程包内同一文件名为 `DEMO-REVIEW.json`。

1. 打开预览 → 设置 → 通用 → 导入数据，选择 `docs/acceptance/2.0.0-dr/demo.json`（工程包选择 `DEMO-REVIEW.json`）。
2. 勾选覆盖当前隔离数据，确认导入。程序先下载导入前的完整 JSON 备份；确认文件已保存且可读后，在浏览器确认框继续。取消或下载失败不会覆盖现有数据。
3. 导入后关闭设置检查任务，打开日程、报表、森林及已完成历史。演示日程在生成当天 9–12 点附近，可滚动时间轴查看。

也可从空白数据开始，直接新建任务。不要把实际私人备份提交仓库。已有真实 Profile 原地升级不属于本轮 D-R 预览。

## 本次观察到的差异及核查边界

以下是本轮候选快照的差异记录，**不是视觉还原已完成的声明**。后续差异状态与用户反馈只归入 BACKLOG E09。

- 字体、图标、按钮/表单形态、颜色、间距、弹窗尺寸和窄屏排列仍与旧版有差异；日期/时间/数值/重复规则使用可操作的原生控件。设置、报表、森林和计时已保留覆盖工作区及关闭返回的行为，具体控件交互仍需用户逐项对照。
- 报表使用 SVG 时长/任务分段图、分布数值和比例条、目标月历；与旧版图表图形、图例及时间线刻度呈现不同。周期导航、任务关联和数值可操作，并非空图占位。
- 森林使用旧树与背景素材，阳光位置、收取/成长动效和成就面板的呈现不同。奖励、收取和成就使用真实持久化服务。
- 导入/清空在下载完整备份后增加浏览器明确确认，不能根据“已发起下载”自动认定已保存。头像上传支持 PNG/JPEG/GIF，受既有服务 512 KB data URL 上限约束。
- 时间戳保留真实毫秒，历史显示 UTC 偏移，跨日按实际区间计算；可能与 A 中记录的旧版 DST 显示缺陷不同，不能以旧错误显示作为正确性基准。
- 原生迷你窗口依赖浏览器 Document Picture-in-Picture；不支持时显示可理解提示并保留主计时操作。系统通知需用户授权，自动背景音受 Web Locks/浏览器播放策略约束。真实 Safari、系统声音/通知及真实用户 Profile 不由本机自动化认证。
