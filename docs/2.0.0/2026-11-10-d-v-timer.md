## 扩大审计的其他修复

- 关联任务摘要改从真实 Pomodoro 记录投影；按旧 5/4 图标阈值、分数图标、运行中番茄与大数值模式显示，替代失真的 actualPomoNum 字段摘要。module 1052 的 SVG 与 1500ms + 1500ms swing 填色也已接回。
- 今日专注总量恢复小时/分钟分段，替代无条件只显示分钟。
- 空态资源恢复 65×70px 和 -8px 文案间距；暂停按钮恢复 100px 最小宽度。
- 旧记录块 module 1120 是只读 div，新版原先点击即打开编辑弹窗。移除此额外操作；日历/报表原有编辑入口保留。
- compact/mini 暂停后的停止统一要求确认（T-02）；计时服务、事务、记录数据结构未重写。
- 白噪音音量恢复拖动时即时保存，取消只取消音轨选择草稿（T-08）。真实鼠标轨迹在旧/新均得到 WNVol=39，取消后仍为 39。
- 白噪音、模式与组件编辑弹窗接入旧 Overlay 淡入/淡出；模式保存失败仍保留草稿，不因动画而吞掉错误。
- 原生全屏 dialog 提前到 layout effect 挂入 top layer，防止 HMR 重启 effects 后父层盖住子弹窗。
- 旧版没有全屏计时器内的独立森林入口；不自行增加新入口。森林原入口及收益/收取由 Domain 回归验证。

## 尚不能宣称完全等价

- 800×600 的局部可滚动容器是针对旧版最小尺寸的承载修复，未把旧版最小 1000×626 内容缩小；与旧版依赖整页最小尺寸的滚动层级不同，需要用户确认。
- 自动化视觉/动画逐帧主证据是 Chromium。Firefox/WebKit 本轮验证业务及页面渲染，没有完成所有动态帧、原生系统 PiP/音效与不同系统缩放的逐像素对照。
- 个别原生输入控件、字体光栅化、按钮内部基线及小型番茄动画的全过程仍不能称为逐像素一致；提供整页差异统计和原图供审核，不调整阈值掩盖差异。
- 通用停止/恢复确认弹窗的内部直接关闭回调仍未统一为完整退出生命周期；不要把本轮主界面进出动画通过外推到所有确认路径。
- 原有 T-01 每秒事务持久化仍在；本轮仅给视觉指针单独投影，不改计时持久化策略。跨模块通用 hover/文字选择差异仍由 BACKLOG E09/W-12 跟进，不做全局替换。
