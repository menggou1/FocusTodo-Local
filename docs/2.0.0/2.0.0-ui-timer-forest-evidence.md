## 组件配置兼容

经原版代码及实际 UI 核实，使用的真实逻辑键是：

| 旧键 | 独立服务字段 | 语义 |
|---|---|---|
| `AllWidgets` | `widgetOrder` | 逗号分隔顺序；缺省或空字符串均按原 getter 回退 `0,1,2` |
| `Widgets` | `visibleWidgets` | 逗号分隔可见组件及顺序；缺省为 `0,1,2`，空字符串表示全部隐藏 |
| `WidgetExpanded` | `widgetExpanded` | 缺省/空字符串为展开，`false` 为折叠 |

类型 0 是今日专注时间，1 是今天任务，2 是今日专注记录。组件通过 `settings.setWidgetLayout()` 和 `settings.set()` 保存，组件本身不直接操作 localStorage。备份继续导出原逻辑键，没有使用推测的 `WidgetList` 或 `WidgetHide`。

`business-services.test.cjs` 已将新字段映射到旧 299 模块的真实 getter，比较缺省、排序、单项、空字符串与展开状态。测试 oracle 只隔离该管理器导入的 React view 674，不替换 getter 实现。新增 `widgets-services.test.cjs` 验证旧键字符串、顺序、空可见列表、折叠状态、备份导出/恢复及无效输入拒绝。两文件实际执行 **10 项通过、0 项失败**。

## 第五轮实际结果

`node tests/standalone/visual-timer-forest.cjs` 的完整执行为 **8 组：4 组通过、4 组失败**，退出码 1。

通过的独立功能组：

- 组件编辑草稿取消、指针/键盘排序、显隐、折叠、重载和空列表再添加。
- 森林未成熟提示、成熟单颗/批量收取、累计 36g 及重载后不重复收取。
- 白噪音草稿不写入、取消回退、试听资源和 35% 音量、确定及重载持久化。
- FlipClock 开始/暂停/继续/停止后累计 60 秒历史、不支持迷你窗口提示，以及本机实际原生迷你窗口单一会话写入。

四个视觉组的实际失败点：

| 场景 | 最后实际诊断 |
|---|---|
| 中文亮色 | 成就首行 y：旧 `295.890625`，新 `300.5`。此前圆盘、时长滚轮、白噪音、模式、FlipClock、组件编辑及森林场景门槛均已通过 |
| 中文暗色 | 组件编辑框像素差：超过 12 灰度的像素比例 `0.012598`，归一化平均绝对差 `0.007988`；平均差超过 `0.003` 门槛。此前圆盘、滚轮、白噪音、模式、FlipClock 均已通过 |
| 英文亮色 | FlipClock 数字截取尺寸旧 `900×427`，新 `900×426`；拒绝对不同尺寸图像直接判通过 |

## 交接诊断

以下是当前事实，不构成新的阶段放行：

- 最新源码已保存暗色组件列表边线修正；最后检查的生产 CSS 仍只有旧 fallback 规则。检查时 `dist/standalone/site/index.html` 为 16:00:10，`legacy-timer.css` 为 16:00:18，说明构建早于该修正 8 秒。下次先冻结各 agent 源码，再统一构建和重跑。
- 最新源码已将焦点时长卡的固定高度从 `section:first-child` 改为类型 0，避免重排后错误压缩历史卡；组件交互组最终通过。
- 最新源码已移除 CSS scroll-snap：现场调试确认它会将键盘 Home 从 scrollTop 0 吸到 60，误保存 120 秒；该修正尚需最新生产构建及三引擎自动休息场景复验。
- 实际旧英文标签是 `Today's Focus Time Records`，新词库原始值包含 `Today''s`；本模块仍直接使用词库，尚未补原格式化转义语义。
- 森林 age=0 的登录记录边界、原随机避碰公式及同数据光球数差异已修正；局部中文亮色场景现已达到门槛。
- 非 reduced-motion 的完整动画时间轴、各等级树/徽章、任务态浮动卡和全部组件组合还没有系统视觉证据。当前功能组使用 reduced-motion，不将它冒充动效体验验收。
