唯一默认参考为可运行的 1.9.3 审计运行时 `f102da8919e810006b6611aabcef5f0159057d61`、A 阶段图像和计算样式。`tests/standalone/ui-restore-helpers.cjs` 在运行前检查旧 `src/public` 与该提交没有差异，分别启动随机 loopback 旧/新服务器，使用两个临时 browser context，阻断外网，复制合成任务与逻辑备份到候选命名空间；没有使用日常 Profile 或私人备份。

## 已落盘的独立实现

- 设置保持旧版 820×600、50px 标题栏、264px 导航、280px 内容起点和48px设置行；默认番茄钟，导航顺序为账号、通用、番茄钟、清单管理、外观、关于。375px 保留旧版两栏和右侧裁切：根窗口375宽，内容从x280开始，未自创移动折叠布局。
- 复用旧字体、设置导航亮暗图标、经典壁纸缩略图、白噪音图片和播放图标。外观为旧版两列270px单元，图片240×160，含选中框、Bing和本地上传；修正旧海洋主题实际保存值 `Ocean`，读取早期候选 `Sea` 的图片别名仍兼容。
- 通用页恢复语言/通知卡片、任务完成音、顶部添加和功能开关。授权后可发送测试通知，窗口恢复焦点时刷新权限。默认禁网点击 Bing 使用原文“请打开外部联网”提示，不发外网请求。
- 番茄长度及两种休息完整保留1–480分钟，长休息间隔保留1–90番茄。独立 `SettingsSelect` 复刻下拉的外形、选项、输入筛选、键盘、Escape和滚动；筛选同时匹配原版标签与秒数值，例如“30”也会匹配300秒的5分钟。语言选项保持不可搜索。底层select只保留语义和受控状态，不再展示系统原生选项菜单。
- 声音页恢复音量、两种完成铃声、白噪音音量和16项两列卡片；range轨道4px、滑块10px，选择与试听继续调用新服务。
- 账号恢复30px头像、用户名失焦/Enter自动保存，以及导出、删除、导入入口。头像保持选择→预览→确定/取消，按旧算法中心裁剪64×64 PNG；最后一次修正还复刻了旧canvas在同一账号页连续选择时的合成行为。
- 备份恢复600px、26px内边距的原对话框、格式单选、体积分析表和下载状态。导出后保留对话框；导入按钮先打开文件选择器，选完后展示校验、分析和覆盖确认；删除没有新加勾选框，保留5秒禁用确认。
- 新增兼容增补 `backup.inspect(input)`：只解码和完整校验，不替换数据库、不写设置、不发安全下载。restore仍执行原安全备份和显式保存确认；取消不会覆盖。

组件、DOM及交互通过独立 React/TypeScript 实现；开关由原生checkbox绘制为旧形状，下拉、range、原生dialog和文件选择由新组件独立管理。它们不是旧 React/vendor 组件本体，因此实现相同外观不表示DOM逐节点相同。生产候选仍不导入旧main.js、patch.js或AST修改脚本。
