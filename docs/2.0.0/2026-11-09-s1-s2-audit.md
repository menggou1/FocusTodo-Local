## 2. S1 基线、环境隔离与端口

权威旧版运行基线：

- 1.9.3 代码：`src/`，应用版本 `7.1.1-local.1.9.3`。
- A 阶段 oracle：`f102da8919e810006b6611aabcef5f0159057d61`。
- 旧版 `src/`、`public/` 与 Tag `1.9.3` 无差异；`f102da8..HEAD` 对旧 `src/public` 也无差异。
- 旧 bundle [`src/js/main.js`](../../src/js/main.js) 的高度压缩组件位于第 409/411/463 行附近；定位时必须同时使用 **模块号 + 字符偏移/函数名**，不能只看行号。

端口职责：

| 用途 | 端口 | 规则 |
|---|---|---|
| 稳定版 | 5500 | **绝对禁止**自动化访问、刷新、截图、读取存储或停止进程 |
| 新版 Vite | 5511 | 显式 `--host 127.0.0.1 --port 5511 --strictPort`，禁止裸 `npm run dev:standalone` 随机端口 |
| 新版构建 | 5512 | `standalone-server --port 5512` 或 `npm run preview:review` |
| 旧版对照 | 5513 | 从冻结 1.9.3 导出启动，`--no-browser --port 5513` |

S1 建议但**尚未形成统一持久 wrapper**的能力：

- 固定端口 + origin 精确断言 + 失败关闭；
- 只关闭测试自己启动的 PID；
- 冻结旧版源码哈希检查；
- 统一禁止 5500 回退。

现状：现有 [`ui-restore-helpers.cjs`](../../tests/standalone/ui-restore-helpers.cjs) 使用临时随机 loopback 端口和旧版哈希检查，D-R1/D-R2/D-R3 又分别显式使用 5513/5511；**没有单一强制 wrapper**。这是追踪清单中的 `ENV-01`，尚无运行时门禁。

## 4. S1 已确认的关键交互事实

这些是审阅旧版源码得到的规则，不因新版重写而改变：

- 清单行 hover 显示行尾菜单并隐藏预计时间/数量；文件夹行主体点击选中，箭头单独展开/折叠。
- 任务行整行点击选中并打开详情；任务空白区点击关闭详情；任务右键有完整菜单。
- 任务完成普通态 250ms 后提交；重复任务 250ms 显示完成、500ms 提交；完成/删除有防重入。
- 任务拖动旧版整行可拖，react-dnd 提供 ghost、目标高亮、前后插入位置。
- 新建任务行有项目、截止日、5 个番茄点 + 数值弹层（可 >5）。
- 计时器根 `.25s all`；浮条/全屏 250ms ease-in；小组件 150ms；FlipDigit 600ms linear；菜单/Overlay 250ms。
- 旧版浮动计时正计时显示分钟整数；所有停止路径先确认；本地适配层每 30 秒/边界才写库。
- 通知面板打开即把到期提醒写已读。
- 白噪音音量拖动即时写 preference；模式选择点确定才写。
- 旧版大量“按钮”实际是 span/div，无 disabled/Tab/Escape；新版应保留合理可访问性，不能机械复制这些缺陷。
