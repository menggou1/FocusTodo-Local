本页归并 2.0.0 开发过程中的主要结论。以下测试结果是对应日期的历史证据，不代表当前版本已通过完整验收；未完成事项及人工验收状态只在 BACKLOG 维护。更细的逐轮记录可从 Git 历史查看。

## 基线和隔离

旧版对照使用 1.9.3 运行文件；最初审计基线为 `f102da8`，后续也核对过 Tag 1.9.3 的运行文件。新旧运行时对照使用隔离的 5513 和 5511、独立浏览器上下文及合成数据，不使用日常 Profile。不同轮次的视口、负载、浏览器和采样方式不同，性能数据不能直接互相比较。A 阶段的存储、功能、依赖、备份及许可取证保留在[基线审计](2.0.0-audit.md)，历史截图位于 `docs/acceptance/`；临时测试结果默认位于 `dist/acceptance/`，可能已被清理或覆盖。

## 独立工程与服务

候选采用 React、TypeScript、Vite 和显式服务，正式旧入口、Pages 与普通便携包没有切换。服务通过独立数据库和设置命名空间隔离；备份仍使用旧逻辑键与 v3 元信息。启动时检查隔离和协议，依序恢复数据库及主题日志、设置、计时和业务状态；无法确认兼容时拒绝写入。接口边界及兼容增补见[服务合同](2.0.0-service-contracts.md)，实际开发命令和存储约束见[维护指南](../MAINTENANCE.md)。

2026-11-08 的服务验证覆盖计时纯核心差分、事务故障恢复、旧备份导入、主题、网络及并发隔离；10 份获授权历史备份在内存比较通过。三引擎检查过候选并发、旧客户端拒写及不兼容 schema/protocol 拒写。相同 schema 和协议下的版本命名往返不证明任意版本可降级，真实 Profile 原地升级仍需按 BACKLOG 验证。

## 界面与交互

- 初期 D-R 人工审查未通过，之后获授权逐页面主动对照旧版。保留独立源码和服务架构；自动化结果不等于用户视觉验收。
- 2026-11-10 的 D-R4 对日历和报表记录了 44 组截图对照、4/4 overlay、三引擎领域测试及日历→计时→报表场景。覆盖范围内通过不表示所有尺寸、动画和真实系统体验已通过。
- 计时器、森林及工作区的 D-V 对照覆盖明暗、中英文、局部几何、指针操作和动画；森林成就列表按用户要求使用 ScrollView，是明确允许的旧版差异。统一文字选择和装饰图片拖动机制曾在三引擎验证，保留输入及可复制内容的选择和合法拖拽。
- 工作区 W1–W7 验证过快速添加、侧栏统计、日期排序、详情栏及重复/提醒/子任务等持久化，包含跨页面操作。2026-11-15 又检查了主工作区两种视口和中英明暗组合，以及设置六页、拖动、主题和备份相关操作。
- 2026-11-10 窗口与滚动条对照使用 1.9.3 与隔离的 Vite 预览，在 Chromium 中覆盖中英文、明暗主题。设置、森林、清单窗口及报表入场的动画采样和设置滚动条交互通过局部对照；任务区滚轮与拖动均能移动内容。新版支持 reduced motion。内容高度不同会影响滑块比例；这些结果不代表其他引擎或整体视觉已验收。复验脚本为 `tests/standalone/window-scroll-equivalence.cjs`，原始输出位于可能已清理的 `dist/acceptance/d-v-window-scroll/`。
- 2026-11-15 设置专项记录类型检查和构建通过，单元测试 60/60、工作区浏览器测试三引擎 60/60、服务浏览器测试三引擎 31/31；Bing 使用可控网络响应，不能据此宣称真实外网验收通过。

局部性能采样曾发现计时小组件收展和森林动画仍有长帧；计时采样中新版为 Vite 开发预览，与旧版生产包的条件不同，不能据此归因或宣称性能等价。实际待修项、真实系统验证和人工审查以 [BACKLOG](../BACKLOG.md) 为准。

### 2026-11-16 · D-V-Calendar

本轮对照未修改的 1.9.3 运行文件（`f102da8`；5513）和独立 React 预览（5511），使用独立 Playwright 无头上下文、合成清单/任务/安排/完成记录、上海时区及固定时间；没有访问 5500 或日常 Profile。未提供独立 Playwright MCP，使用仓库锁定的 Playwright 运行时。旧源码、实际 DOM、computed style、指针/键盘操作和 IndexedDB 回读共同作为依据。

| 用户问题 | 本轮结果与依据 |
|---|---|
| 1–3 | 拖动创建保留松手后的草稿块，名称及番茄时长同步预览；空名称按旧版显示内联“请输入任务名称”、聚焦输入框，去掉浏览器原生验证提示路径；调整柄在移动时实时绘制，松手后提交一次。 |
| 4–5 | 点击空白关闭日程详情；选择栏和日程详情互斥，只保留一个独立详情栏。这是本轮明确允许修正的旧版叠层缺陷。 |
| 6–7 | 恢复任务栏的宽度、38px 番茄行、无番茄任务行、图标、清单夹层级和清单/标签筛选；按旧版 order/creationDate 排序。指针拖入显示浮动任务和安排预览，松手写入真实安排。 |
| 8–11 | 右键只打开“复制 / 删除”菜单，190px 宽、24px 行高和 250ms 收展；删除直接软删除，不弹确认。日程原始记录剥离展示用 type，避免 expected 冲突。详情底栏图标恢复 24px，复制安排包含旧版短休息间隔。 |
| 12–14 | 新建安排和主工作区详情共用的清单菜单恢复颜色、选中标记、尺寸与可选清单。完成记录打开日程侧栏，不弹编辑窗口；恢复项目色、白字、秒/分/小时文本、短块布局及最小高度。历史/报表原有记录编辑弹窗保留。 |
| 15–18 | 日期选择浮层复用现有 PickerField/DatePicker，修正位置、内部间距和箭头；周视图使用旧版时间范围、颜色和重叠规则；月视图按实际月份周数绘格，任务可换行，超过三条显示 +N，点击日期/任务进入日视图。恢复今天红线、每分钟更新及非今天隐藏；未来日期单列，今天和过去双列。修正 1024px 下继承 padding 导致的整体偏移，以及侧栏断点、滚动条和 hover。 |
| 四类清单弹窗 | 创建/编辑清单和清单夹恢复居中标题、312px 宽度、输入间距、20 色及选中图片、按钮和清单勾选行；清单归属通过清单夹编辑管理，保持已有归属与持久化逻辑。 |

主动对照还覆盖跨午夜安排拖动保留原始起点、日视图滚动位置、右键边缘翻转、拖拽后的点击传播，以及深色原生滚动条。日/周轴恢复 6px 原生滚动条；详情及清单菜单接入现有 ScrollView 反馈。删除时间格多余的粉色 hover，恢复开始按钮 hover、调整柄显隐和拖拽光标。快速创建有两种实际位置：拖动创建以已绘制的预览定位，双击创建居中；没有仅根据源码中的定位意图推断行为。

验证入口为 `tests/standalone/calendar-parity.cjs`，并更新 `calendar-overlay-equivalence.cjs`、`domain-pages.cjs` 和 `workspace-browser.cjs` 中已被旧版行为替代的测试路径。结果：日程主动对照 10 组通过；`visual-calendar-reports.cjs` 中英/明暗 44 组截图的已测几何与样式断言通过；浮层交互 4/4 通过。类型检查、独立构建和语法检查通过；单元测试 92 通过、1 个平台跳过；服务单元测试 52/52。三引擎领域页面 33 个场景、工作区 60 个场景经初跑及针对性复测覆盖通过。

集中回归曾发现快速创建字段高度误作用于浮层容器，导致番茄选择器越出视口，已限定样式作用范围后在三引擎复测。工作区 WebKit 初跑期间重建产物导致后续启动超时；固定产物后完整重跑 WebKit 20/20 通过。构建保留现有大 chunk 提示。截图、日志和临时脚本仅用于本轮诊断，结束前清理 `.agent-temp/d-v-calendar/`；可追溯依据为上述测试源码与本次提交。自动化覆盖不代替人工验收，真实系统/DST 等既有边界仍以 BACKLOG 为准。
