发布准备时将本批次的有效改动归入中英文版本报告。未完成事项维护在 [BACKLOG](BACKLOG.md)。

2.2.0 主工作区交互与搜索优化，兼容现有任务、清单、日期与备份数据。

## 范围

任务创建及日期选择、分组文字布局动画、侧栏放置与工作区排序、详情删除、1.9.4 报表悬停对照、搜索索引和交互，以及 CI #189 的 Python 备用服务排查。

## 验收要求

使用隔离构建与合成数据，覆盖三平台、Node 22/24、三种浏览器引擎、中英文和明暗主题。核对日期与删除的持久化结果、排序边界、拖动取消与写入失败、原有动画，以及旧数据升级。搜索验证含 300ms 防抖、回车、Escape、通知跳转、输入法合成、同一任务详情保留及四种规模的服务耗时对照。

## 已完成改动

- 创建框输入文字使用 1.9.4 的明暗主题颜色。主任务和子任务的加号与回车共用提交入口，空白输入和重复点击有回归覆盖。
- 创建框图标、弹窗初值与提交共用已保存的默认截止日。带有 2026-09-29 默认值的合成旧备份可保留历史任务与原日期，明确选择并确认「待定」后保存 `0`，切换工作区、重载和备份往返后仍一致。详情快捷按钮复用日期选择状态，第三个按钮显示「未来七天」或「Next 7 Days」。
- 分组标题和已完成区开关复用任务原有布局动画。拖拽侧栏标识有效目标并加强悬停提示，放置按清单归属、截止日、标签和优先级分别处理。任务成功离开当前工作区时，拖影朝目标退场。取消和写入失败时，拖影回接原任务。
- 按清单分组的清单夹中，每个清单独立排序。跨清单区域显示灰色遮罩和引导提示。「已计划」等日期聚合视图拖动期间显示遮罩，工作区释放不会写入顺序。服务层校验任务与目标状态，并拒绝跨清单的排序写入。
- 详情与右键菜单共用相同删除确认、重复任务选项和任务、子任务、专注记录删除流程。
- 报表前三项恢复 1.9.4 悬停交互。默认显示小时和分钟，悬停切换对应时段的番茄数及标题。番茄数最多一位小数，离开恢复原显示。
- 搜索按快照为任务和活动子任务建索引，复用最近的规范化关键词结果。匹配任务名、备注、标签和子任务，保留已完成及找不到清单的任务。搜索结果按清单顺序分组，组内保持任务顺序，隐藏顶部统计、创建和排序入口。
- 只在 300ms 防抖到期或按回车时提交关键词。导航取消待触发的搜索，结果变化时保留仍匹配的详情，清空后按 Escape 可直接返回来源清单，输入法合成结束后再安排搜索。
- 为 Python 备用服务测试补充启动和请求阶段诊断，将测试取消传给 HTTP 请求。CI #189 首次作业日志确认两项测试各触发原有 10 秒超时，同 SHA 的第二次运行通过。[首次失败作业](https://github.com/menggou1/FocusTodo-Local/actions/runs/45179802683/job/137710995266) · [CI #189](https://github.com/menggou1/FocusTodo-Local/actions/runs/45179802683)
