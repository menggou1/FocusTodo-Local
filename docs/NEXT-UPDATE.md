# 下一版累计更新

本页记录最近一次归档之后已完成且尚未归档的改动。准备下一版时归纳到对应的中英文版本报告。未完成事项继续维护在 [BACKLOG](BACKLOG.md)。

## 2026-11-22

- 备份检查和恢复入口共用目标历史校验，拒绝损坏的目标记录与非文本名称。使用 v1 JSON 和 v2 Gzip 验证拒绝时原数据库、设置、计时快照和安全备份次数均保持原样，并验证旧版缺名记录导回后能搜索、扩展字段仍在。
- 完成或删除任务时，如果解除计时关联首次发现待确认的中断，整个业务事务回滚。服务回归核对任务、子任务和计时会话的持久化结果，并在确认中断后验证重试只保留获确认的 60 秒记录。
- 每日专注目标按本地自然日更新。三引擎回归核对纽约秋季回拨时修改日程和专注记录的时长仍保留第二次出现的开始时刻，在日历中选日后写入正确的本地日期，以及在无效区域放开拖拽后保留原日程。
- 两个标签页在同一存储锁下合并提醒已读记录。系统通知构造失败时保留应用内未读状态，继续调度下一条提醒，每次到期在同一页面内只尝试一次系统通知。
- 独立迷你计时器恢复 1.9.4 的背景亮度、入场淡入和左右窗口按钮。保留缩放时计时控件整体居中及主窗共享会话。原生小窗明暗复测覆盖 147×58、232×58、放大和缩小、专注、暂停、休息及重新打开。
- 设置的八个下拉按钮只在可见控件内响应点击。回归实际点击行内文字、按钮外空白和控件，并核对焦点、键盘及触控选择。“外观”的壁纸区域更名为“背景”，沿用原有设置键和选择逻辑。
- 修复 `67ddc15` 引入的计时动画回归。按 `58853d2` 恢复 330px 卡片随侧栏滑动的 150ms 线性收展，以及组件松手后从预览原位置沿双轴接续的 180ms `ease-out` 排序。仅在侧栏与编辑器内容层隔离布局，保留原有可视边界、浮层层级、相邻组件让位和确认保存。动态对照检查收展、75ms 反向、斜向放下和越界回弹，同时记录 `scrollWidth` 与 `clientWidth`。
- 关于页展示本地版版本和作者、来源项目、离线存储、项目仓库及许可。移除帮助和反馈入口，把官方版本下载移至末尾并链接至 Focus To-Do 官方下载区。
- 更新详情固定左上角磁贴、标题和确认区，只滚动更新条目并复用应用滚动条。小窗内核对首尾滚动时各固定区域的位置，以及历史和最新条目的既有已读规则。
- 专注时长柱图在聚合投影中独立排列任务和自定义清单。任务依据既有优先级和顺序排列在前，自定义清单采用保存顺序。回归核对日、周、月、年四种周期的最终分段、聚合秒数、多条记录和提交后刷新。短分段按设备像素共享边界，90 秒绿色分段在 Windows Chromium DPR 1 和 2 均保留精确颜色。
- 设置视觉对照解释了白噪音区域的 48px 位移，该位移等于移入计时设置的任务完成提示音一行。对齐白噪音视区后，按钮、图标和音量滑块与 1.9.4 的几何对照通过。导入、导出的固定标题和滚动正文恢复为原有总间距，英文深色导入预览对照从三处几何差异降至零。
- 报表番茄记录的滚动条随记录视区定位并裁切在圆角内。滚动只更新对应的滚动条位置，保存已有记录后直接更新分段。2,920 条合成记录验证了滚轮、键盘、拖动滚动条和内外滚动交接，滚动期间无 Canvas 尺寸重置。保存记录后的揭示进度保持为 1，原实现会重新播放入场动画。
