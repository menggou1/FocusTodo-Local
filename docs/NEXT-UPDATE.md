# 下一版累计更新

本页记录 2.1.2 之后已完成且尚未归档的改动。准备下一版时归纳到对应的中英文版本报告。未完成事项继续维护在 [BACKLOG](BACKLOG.md)。

- 正式版及隔离预览的构建产物只允许哈希匹配的内联启动代码。本地 Node/Python 启动器禁止嵌入页面，并限制运行清单及请求目标。
- 备份及导入前安全副本省略外部联网许可。导入保留主题和缓存壁纸，成功后可在设置中重新授权 Bing 联网。
- CI 固定 Actions 提交及浏览器镜像摘要，限制复用附件的压缩和解包大小。首次发布核对版本 Tag 和远端同版本发布分支的精确 SHA，发布完成后再同步 main、dev 并验证 Pages。

## 2026-11-21

- 恢复任务完成反馈。普通任务立即显示完成状态并保留原行约 250 毫秒，重复任务先旋转完成图标，再显示完成状态并在约 500 毫秒后移出原位置。任务及重复实例的事务在操作时提交，其他页面读取已提交的记录。
- 任务和自定义清单拖动时保持浮动项在上层，其他条目平滑让位。松手时从拖动位置接续到落点，提交失败时回到当前已保存的顺序。
- 系统清单方向键排序依次处理连按和反向输入，从正在显示的位置接续动画。番茄钟右侧组件编辑器的拖动和方向键调序也使用相同的位置过渡，确认后才保存组件布局。
- 报表的完成任务柱状图独立排列任务类别和自定义清单。任务类别按优先级和任务顺序排列并显示在上方，自定义清单沿用各自保存的顺序。原始完成数量和任务归属保持一致。
- 清单夹的新建任务菜单只显示“任务”及直属可见清单。创建事务重新校验目标归属，清单移出、隐藏或删除后回退到“任务”。
- 导出数据窗口使用与应用一致的滚动条。滚动区域位于窗口内侧，左右圆角保持对称，支持滚轮和键盘滚动。
- 修复 HMR 预览启动时的 `_jsxDEV` 报错。开发预览使用 React 开发运行时，浏览器验收使用独立临时依赖缓存。
- Linux CI 的 Playwright 镜像检查在 Bash 中执行，并继续校验镜像版本与摘要。
