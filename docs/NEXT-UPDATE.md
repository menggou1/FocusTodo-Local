# 下一版累计更新

本页记录 2.1.0 发布后已完成的改动。发布下一版时归纳到对应的中英文版本报告；未完成事项继续维护在 [BACKLOG](BACKLOG.md)。

## 2026-11-19

- Windows 隔离预览的 `-Open` 改用临时 Edge 会话，不再复用日常浏览器配置。新增 `-Static` 备用方式，从同一源码构建并启动不依赖 HMR 的隔离服务。[预览命令](MAINTENANCE.md#环境与正式入口)
- 启动失败页显示失败阶段、未完成阶段及可取得的错误原因；界面渲染失败页也显示错误详情。两处均可复制详情，剪贴板不可用时可手动复制已选文字。
- 错误窗口沿用应用确认窗口的字体、按钮和明暗配色，详情改为可选中的换行文本及细滚动条；外层启动错误窗口沿用加载窗口左上角的图标磁贴。
- 修复 5511 因同源旧设置或旧数据库无法启动的问题。预览只读写自己的设置和数据库，保留原有数据，不需要换地址或清空数据；仍验证服务证明及预览数据库的版本。
- 任务完成音改为随应用脚本内嵌，不再向本地服务请求独立的 `Complete.m4a`，避免 IDM 将内置提示音拦截为下载。
- 恢复 HMR 预览的 Vite 终端快捷键，并可输入 `f` 后按 Enter 刷新已连接的预览网页。
- 修复备份导入后有效头像被替换成默认图的问题：工作区、账号资料和森林均可显示带折行或大小写差异的内嵌 Base64 头像，也支持 JPEG 简写和 WebP；坏图仍回退到默认头像。
