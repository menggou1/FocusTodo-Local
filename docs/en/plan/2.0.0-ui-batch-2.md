# 2.0.0 Phase D second batch: tasks and timer

[Maintenance](../MAINTENANCE.md) · [Roadmap and human gate](2.0.0.md) · [Open work](../BACKLOG.md) · [中文](../../plan/2.0.0-ui-batch-2.md)

2026-11-08 (Asia/Shanghai), based on `503fc62`, continuing functional D work on `refactor/standalone-app`. No production entry switch, merge, push, PR or release. Core services and frozen v1 contracts are unchanged.

Delivered integration includes tag creation/edit/deletion and task tag selection/filtering; saved list colors; legacy grouping values (0 project, 1 deadline, 2 priority, 3 custom), subtask pointer/keyboard ordering and task drops onto list/tag/date/priority entries. Sidebar pointer/keyboard resizing persists within the existing 180–380px preference range. Task summaries include estimates, remaining tasks, elapsed focus and completed tasks independently of finished-row visibility.

The floating/expanded timer subscribes to C sessions. Task/subtask start expands it; stopwatch/countdown, pause/resume, stop, breaks/completion, detach, duration and associated-task completion call existing services. Recovery uses the service interval, millisecond cutoff and continue/pause/exclude choices; closing the dialog leaves an action to reopen it. Local sound selection, audition/stop, volumes and task completion sound are connected without moving audio ownership into components. Native PiP renders a React portal with the same commands/session; missing/failed PiP leaves an operable in-page timer. Actual local adapter paths determine legacy stop/mode/rest behavior, rather than unused upstream methods. Legacy source is read only for development comparison, never imported at runtime.

Build/package, three-engine workspace/startup and extracted-archive checks are described by the [evidence summary](../../acceptance/2.0.0-d2/summary.json). Tests cover tags/colors/grouping, persisted width, cross-list drag, subtask pointer/keyboard order, timer associations/history/25-second threshold, mode reload, recovery, breaks, sound preferences and mini fallback. Chromium additionally opens native PiP and operates start/pause/stop with a single TimerSession. Media call/preference tests do not establish real system playback acceptance. Chinese/English, light/dark, 375px and reduced-motion checks retain A typography/geometry assertions and the negative injection.

D remains in progress. Unconnected routes are explicitly excluded from completion and cannot be delivered as D-R. Remaining pages and interaction details live only in BACKLOG E09; explicit-save details and recurrence-field forms are interaction differences, not merely visual polish. This batch does not start concentrated D-V work or declare visual acceptance.

Once all D functionality and page-render/operation checks pass, D-R delivers a runnable preview, startup instructions and known differences, then pauses subsequent work for the user's inspection. Completed D-R plus explicit user authorization is required before D-V; never auto-enter D-V, E or F. WebKit is not Safari, and system audio/notifications/real profiles retain their existing acceptance limits.
