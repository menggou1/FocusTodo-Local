# 2.0.0 engineering sequence

The app uses complete React/TypeScript/Vite sources, explicit services and existing v3 data compatibility. See [Architecture](../ARCHITECTURE.md) and [Testing](../TESTING.md).

Preparation: repair code/docs, validate locally, commit/push, await CI, then open the review PR. Merge, tags, Release and live deployment require separate authorization under [Maintenance](../MAINTENANCE.md). Unfinished work is maintained only in [Backlog](../../BACKLOG.md).
