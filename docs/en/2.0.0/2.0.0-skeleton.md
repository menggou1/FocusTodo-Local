## Delivered boundaries

B01 locks React/ReactDOM 19.3.1, TypeScript 7.0.2, Vite 8.3.6, React plugin 6.2.1 and their types; Node 22.12+ is required. Navigation uses a reducer, and services expose stable snapshots and subscriptions. No Redux or router is introduced. See the [dependency decisions and license sources](2.0.0-dependencies.md).

B02 separates composition and contracts (`standalone/app`), pure version rules (`domain`), injected adapters (`services`), components (`features`), language helpers, styles and optional assets. Components call services; services never import components or legacy globals. Transactions and timer lifecycle have not moved into components.

B03 provides an independent inline startup screen, required resource failure/retry, a React ErrorBoundary, Chinese/English fallback, light/dark/system themes, keyboard and narrow layouts, and reduced motion. Required styles must report successful loading before mounting. Optional dynamic imports and JSON can fail, retry or be cancelled without blocking the shell. The layout reuses audited color and sizing tokens with system fonts; it does not claim Phase D visual or functional parity.

B04 uses a dedicated server on a random loopback port and a fresh browser context. Startup requires the server's exact-origin response, rejects every existing IndexedDB database or localStorage key outside `FocusTodoStandalone.`, and fails closed when database enumeration is unavailable. Tasks exist only as read-only synthetic memory samples. Only explicit prototype language/theme preferences are persisted. No real database is opened or migrated.

B05 uses relative `base: './'`, a separate runtime layout and an explicit generated manifest. The root path and `/FocusTodo-Local/` path work from the built directory and both extracted archives. The packages contain their own dependency-free Node server, full root/React/ReactDOM/scheduler license texts, and no legacy bundle, fonts, photos or audio. Root package metadata was corrected from ISC to the existing LICENSE's MIT; this does not complete the legacy asset notice audit E17.

Version metadata continues to come from `release.json`. Pure tests distinguish `1.9.3 → 7.1.1-local.1.9.3` and `2.0.0 → 2.0.0` while preserving source version 7.1.1 and schema v3. The normal generator has not switched product versions.

## Reproduce

```powershell
npm ci
npm run build:standalone
npm run start:standalone
```

Open the printed random loopback URL in a fresh context. `npm run dev:standalone` provides isolated Vite source debugging and hot reload. Hidden sourcemaps and the Vite manifest live in `dist/standalone/debug/`, outside the served and packaged `site/`. Before cleaning outputs, the build rejects any existing symlink/junction or non-directory ancestor.

```powershell
npm run package:standalone
npx playwright install chromium firefox webkit
npm run test:standalone
```

Extract either `FocusTodo-standalone-prototype` archive in `dist/standalone/` and run `node start.cjs`, or `node start.cjs --base /FocusTodo-Local/`. No npm install or CDN is needed to run. These artifacts are separate from normal releases.

## Actual evidence

Windows, Node 24.16.0, npm 11.16.0 and Python 3.11.8 were used locally; the normal packaging/CI Python requirement remains 3.12+. A clean `npm ci`, type check, build, package and complete prototype acceptance passed. Tests used Edge 156.0.4314.58, Firefox 153.0 and Playwright WebKit 26.5, fresh temporary origins, synthetic data, Asia/Shanghai, DPR 1 and 1280×900 or 375×812 viewports with external networking blocked.

- Seven unit tests cover isolation, legacy/unknown keys and databases, version separation, language fallback and server manifest/source-map boundaries.
- Forty-two browser scenarios cover three engines, root/project paths, both languages, themes, keyboard, narrow layouts, preference reload continuity, optional delays/failures/retries, preservation and rejection of old storage, missing server response, required JS/CSS failure/retry, persisted lifecycle and React boundary recovery.
- Both real ZIP/tar.gz extractions start from paths containing spaces and Chinese characters, under the project subpath with external networking blocked and without npm, Git, legacy code, maps or user data.
- The Vite development entry mounted in isolated Edge without page errors and exposed source modules for debugging.
- Existing application unit tests passed 92 cases with one POSIX wrapper case skipped on Windows. Legacy syntax checks, five release-gate tests and two Pages build tests passed; `build:release` preserves the existing runtime contents. Full dependency `npm audit` reported no known vulnerabilities.

Acceptance found and fixed Firefox mounting after required CSS failure. Early listeners and direct generated link/script event handlers now record completion or failure, and mounting requires success. Persisted `pagehide` preserves the root and services; actual non-cached departure disposes them.

The final site totals **251,823 bytes**; main JS is **234,372 bytes** (73,306 bytes with the local per-file gzip measurement), CSS **7,283 bytes**, ZIP **86,226 bytes** and tar.gz **81,249 bytes**, excluding private maps. These are prototype measurements, not full-application or production performance promises. Summary, scenario results, sizes and three representative screenshots are archived in `docs/acceptance/2.0.0-b/`; reruns still write `dist/acceptance/`.

CI is configured to build one candidate in preflight, run new unit tests in all six OS/Node jobs, test the same built site and both archives with Chromium in all three Node 24 jobs, and additionally run Firefox/WebKit on Linux. This report records local evidence; it does not claim unexecuted remote CI passed. Normal release gates and main-only Pages remain unchanged.

## Evidence limits

Offline means external networking is blocked while the local HTTP server remains available. There is no service worker, `file://` support or uncached remote first-visit offline guarantee. The Pages-style path was tested locally; no candidate Pages deployment occurred.

The ErrorBoundary uses a test-only in-memory build with a real throwing React child and retry; the product's first render was not fault-injected. Persisted page lifecycle coverage uses synthetic events, not a confirmed real bfcache hit. WebKit is not real Safari. Syntax targets are not proof of minimum-browser execution, and the isolation API requires Firefox 126+.

B01–B05 are delivered within these boundaries. This work stops at B. Subsequent implementation and real-environment acceptance status remain solely in [BACKLOG](../BACKLOG.md).
