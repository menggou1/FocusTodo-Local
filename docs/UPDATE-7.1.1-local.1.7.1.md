# 7.1.1-local.1.7.1 — 本地专注森林与成就

[更新记录](../CHANGELOG.md) · [维护指南](MAINTENANCE.md) · [English](en/UPDATE-7.1.1-local.1.7.1.md)

发布日期：2026-10-30。作者：Lexible。

## 更新内容

- 恢复原版专注森林开关、入口、树木、阳光、动态和攻略。森林及奖励不依赖账号服务器，小组和在线排名继续排除。
- 原版阳光由已保存的番茄、完成任务和本地登录生成，24 小时成熟、48 小时过期；取消每日收取上限。攻略补充实际计算、等级、备份和收取规则。
- 原排行榜抽屉改为本地成就，使用现有徽章入口和铜、银、金奖杯。专注时长、完成任务数和专注记录结束所在自然日各设三个等级；奖励分别为 20、100、500g，解锁后直接一次性计入阳光。旧记录参与计算，已获成就不会因删除记录撤销。
- 保持阳光位置，修复快速收取和角标计算；收取失败后恢复显示。兼容旧数据中无效的阳光余额。

- 网页以相对路径声明标签图标，项目子路径下也可加载；成就入口复用徽章图案并采用与攻略相呼应的圆形按钮。

- 1.7.0 的 main 工作流在 macOS 日程验收中，恢复数据后立即检查渲染数量时偶发读到 0；保存的三条计划已在恢复前确认。验收改为等待界面渲染完成后检查。1.7.0 标签工作流通过并已发布，保留其标签。

## 数据与兼容

森林余额、收取记录和成就解锁状态使用本地设置保存，并随完整备份导出和恢复；数据库保持 `PomodoroDB6` v3。收取与成就发奖使用现有维护锁，成就解锁和对应阳光在同一设置值内提交，避免重复奖励。日常数据和实际账号不进入仓库或测试。

## 验证与发布

本地验证使用独立浏览器上下文，覆盖原森林开关与界面、阳光生成和收取、无每日上限、原排行榜样式成就抽屉、实时解锁、跨标签页去重、重复备份恢复、失败回滚和中英文攻略。完整测试、便携包及发布过程遵循[维护指南](MAINTENANCE.md)。
