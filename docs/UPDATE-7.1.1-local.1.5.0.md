# 7.1.1-local.1.5.0 — 字体、清单排序与滚动修复

[更新记录](../CHANGELOG.md) · [维护指南](MAINTENANCE.md) · [统一待办与验收](BACKLOG.md)

发布日期：2026-10-27。

- 英文普通界面使用随包附带的 Noto Sans 可变字体，下载期间显示回退字体，完成后自动切换；中文仍使用附带的 Noto Sans SC。恢复组件各自的字体声明，番茄钟等专用字体不再被全局根节点强制覆盖；界面和数字字体支持加载期间回退。Noto Sans 版权及许可随字体一同交付。
- 设置中的清单管理支持拖动及聚焦行后的上下方向键排序。系统清单与自定义清单分别排序，不能跨组移动；使用数据库事务保存顺序，并更新当前界面。隐藏与删除操作保持原有行为。
- 清单管理的外层容器只裁剪内容，内部列表负责滚动，修复到底部时出现第二个滚动条。
- 继续 E08 网络兼容维护：复用 XHR 时清理上次阻断状态，同源绝对地址可以正常访问，旧的用户接口兼容和外部白名单仍保留。其他待办见统一清单。

## 验证

`1.4.4` 对应提交 `e374b532` 完成六项跨平台 CI 与 Release 发布；经确认版本语义后调整为 `1.5.0`，保留已推送的 `1.4.4` Tag。版本修正仅更改元信息和文档，未重跑测试工作流。

本地 Node 测试 57 项通过，1 项 POSIX 用例在 Windows 跳过；语法检查通过。隔离浏览器验收包括 14 项启动、59 项应用与 7 项维护场景；系统及自定义清单拖动、跨组限制、键盘排序、刷新保留与滚动区域另经针对性验证。ZIP 和 tar.gz 解压启动与错误标签拒绝检查通过。实际环境的未完成验收仍列于统一待办。
