## 实现与接口

| 任务 | 本次交付 |

| B01 | React/ReactDOM 19.3.1、TypeScript 7.0.2、Vite 8.3.6、React 插件 6.2.1 及类型依赖精确锁定；Node 最低 22.12.0。选择 reducer 导航和服务快照/订阅，无 Redux 或路由库。依赖及官方许可来源见[决策记录](2.0.0-dependencies.md)。 |

| B03 | 必需样式加载成功、隔离检查完成后挂载 React；独立内联首屏在必需脚本/样式失败时显示重试。提供 React ErrorBoundary、中英回退、亮暗/跟随系统、键盘导航、窄屏及减少动态效果。动态 import/JSON 可选加载失败不阻塞使用，可以重试及取消。 |
| B04 | 构建候选和 Vite 调试服务均绑定随机 loopback 端口，要求全新浏览器上下文和专用服务器响应。任何已有 IndexedDB、非 `FocusTodoStandalone.` 的 localStorage 键或无法枚举数据库均阻止启动。任务为只读内存合成样本；仅显式语言/主题选择写入自身命名空间。旧客户端和真实数据库不参与。 |
| B05 | 相对 `base: './'`，由独立运行清单与 manifest 限定 `dist/standalone/site/`，在根路径和 `/FocusTodo-Local/` 项目路径验证；两个原型压缩包完整解压后通过独立 Node 服务运行，无 npm/CDN/旧 bundle。 |

候选样式复用已经审计的红色、亮暗色及三栏布局尺度，使用系统字体；没有引入未核对声明的旧素材。这是布局骨架，未宣称与 A 阶段全功能页面视觉等价。日程、报表、计时、森林等导航显示迁移说明，日常功能继续由现有应用提供。

`release.json` 仍是版本来源。纯函数使用样本测试 `1.9.3 → 7.1.1-local.1.9.3`、`2.0.0 → 2.0.0`，独立保留来源 `7.1.1` 和 schema v3；未提前切换正式生成器或迁移数据。

## 构建、调试与包

从干净依赖安装执行：

```powershell
npm ci
npm run build:standalone
npm run start:standalone
```

打开打印的随机本地地址。源码调试和热更新使用 `npm run dev:standalone`；生产构建的 hidden sourcemap 和 Vite manifest 移到 `dist/standalone/debug/`，候选服务及压缩包不提供这些文件。构建前检查输出目录的全部已存在祖先，拒绝 symlink/junction 后才清理输出。

```powershell
npm run package:standalone
npx playwright install chromium firefox webkit
npm run test:standalone
```

两个 `FocusTodo-standalone-prototype` 包位于 `dist/standalone/`，完整解压后运行 `node start.cjs`，项目子路径用 `node start.cjs --base /FocusTodo-Local/`。它们与正式便携包及 Tag 发布隔离。内附根 MIT 和 React、ReactDOM、scheduler 的完整版权/许可文本；本次也将根 package 元数据的 ISC 更正为与 LICENSE 一致的 MIT，不代表 E17 全部旧素材声明已核对。

## 实际验证

本机 Windows、Node 24.16.0、npm 11.16.0、Python 3.11.8；项目正式打包/CI 的 Python 合同仍为 3.12+。`npm ci` 后重新执行类型检查、构建、打包和完整候选验收均成功。浏览器为 Edge 156.0.4314.58、Firefox 153.0、Playwright WebKit 26.5，测试使用隔离临时来源、合成样本、Asia/Shanghai、DPR 1、1280×900 或 375×812，并阻断外网。

- 7 项候选单元测试：来源及服务器响应、拒绝旧/未知键和旧库、不写真实存储、版本分离、语言回退、服务清单和源码/map 隔离。
- 42 项候选浏览器场景：三引擎根路径/项目子路径、中英、亮暗、键盘、窄屏、偏好刷新连续、可选资源延迟/失败/重试、旧设置/DB 保留且拒绝启动、缺少专用服务器响应、必需 JS/CSS 失败及重试、页面恢复生命周期和 React 错误边界。
- ZIP、tar.gz 真实解压包均从带空格/中文的临时目录启动，通过外网阻断下的项目子路径访问；包内无 npm、Git、旧包、调试 map 或用户数据。
- Vite 开发入口在独立 Edge 上成功挂载、无页面异常；开发源码模块可定位。
- 现有应用单元测试 92 通过、1 个 POSIX 包装用例在 Windows 跳过；旧语法检查、5 项发布门禁及 2 项 Pages 构建测试通过。`build:release` 生成内容与原入口一致。完整依赖图 `npm audit` 为零已知漏洞。

验收同时发现并修复了 Firefox 必需样式失败后仍挂载的问题：资源监听先于外部资源，同时在生成 HTML 的必需 link/script 上记录完成或错误事件，挂载仅接受成功事件。`pagehide.persisted` 时保留 React 和服务，防止恢复成空白；非缓存离开才释放订阅和根节点。

最终候选站点合计 **251,823 字节**，主 JS **234,372 字节**（本机逐文件 gzip 测量 73,306 字节），CSS **7,283 字节**；ZIP **86,226 字节**，tar.gz **81,249 字节**。体积含运行库、声明及合成资源，不含调试 map；这些是本次原型测量，不是完整应用或线上性能承诺。概要、逐场景结果、体积及三张示例截图归档在 `docs/acceptance/2.0.0-b/`；重跑输出仍写 `dist/acceptance/`，不会覆盖归档。

CI 已配置为预检构建候选，六个 Node/系统作业执行新单元测试，三个 Node 24 作业使用同一份候选产物验证 Chromium 和两个解压包，Linux 追加 Firefox/WebKit。此报告记录本地执行证据，未把尚未运行的远程 CI 写成通过。正式发布门禁与 Pages 的 main 限制保持原规则。

## 证据边界

“离线”指本地 HTTP 服务可用、外网被阻断时的冷启动；未使用 service worker，不保证 `file://` 或未缓存远程网站断网首次访问。项目路径是本机 Pages 风格路径，未部署候选到正式 Pages。

ErrorBoundary 用测试专用内存构建入口验证真实 React 子组件抛错和恢复，没有给产品增加故障按钮；这不等于对产品首次 render 做过故障注入。页面缓存恢复覆盖合成 `pagehide/pageshow.persisted` 分支，未将它写成真实 bfcache 命中。WebKit 自动化不等同真实 Safari；语法 target 不等同测试过最低浏览器，隔离检查还要求 `indexedDB.databases()`，Firefox 需要 126+。

B01–B05 在上述范围内交付并具备进入服务迁移的工程基础；本轮工作止于 B，不执行 C。后续工程和真实环境验收状态继续只由 [BACKLOG](../BACKLOG.md) 维护。
