## 组合与持久化边界

`services/application.mjs` 组合全部服务，`browser.ts` 只提供原生能力与生命周期。启动依次为隔离确认 → DB/协议与导入日志 → 主题日志 → 身份/设置 → 计时 → 业务快照、提醒与调度。失败保留存储并拒绝继续。隐藏/离开释放音频，非缓存离开释放服务；无 BroadcastChannel 时通过受限轮询及焦点/存储事件刷新。

物理库为 `FocusTodoStandalone.PomodoroDB6` v3 及独立锁库，设置物理前缀 `FocusTodoStandalone.data.`。备份仍为旧逻辑键及 `PomodoroDB6` v3 元信息，未知字段和 Group/GroupUser/Message 兼容数据保留。`LocalMeta` 保存协议 1 的独立客户端族标记，不更改 schema，也不将内部元信息写入业务备份。正式客户端与候选不能共用真实数据库；改产品版本名不等于数据迁移。

候选页面只注入 `ApplicationServices`；构造时剔除 repository，类型和实际对象均不向组件提供事务。测试用全局只在内存构建的测试入口存在。候选从正常源码构建，无旧 bundle、模块编号或旧全局的运行时依赖；旧生产实现与旧 oracle 的退出由 E 处理。

## 兼容矩阵

| 组合 | 实测结果 / 允许条件 |
|---|---|
| 候选 + 候选，原生 Web Locks/广播 | 三引擎同一计时的写入不重复；广播刷新已提交快照。原生锁只允许一个自动背景音所有者，暂停后交接。 |
| 候选 + 候选，无 Web Locks/广播 | IDB 事务串行计时；独立锁库活事务覆盖维护，另一启动者不能超时抢锁；拥有者页关闭后恢复。轮询刷新任务。自动背景音关闭，手动试听/完成铃声可用。 |
| 维护、崩溃、配额失败 | 行提交后重建恢复设置；设置失败恢复原数据；再次回滚失败保留 rollback 日志。三引擎关闭所有者页，另有 Chromium 实际 renderer crash 后的新页恢复。 |
| 固定 B 客户端 + C 数据 | B 原隔离检查在三引擎拒绝启动，不写 C 数据。 |
| 旧正式库/未知库 + 候选 | 启动拒绝；旧 sentinel 原值保留。数据工厂在发出 open 前拒绝正式库名；不支持将新旧客户端直接挂到同一正式库。 |
| 合成 v2 → 候选 v3 | blocked 时立即失败，解除后旧请求也不悄悄升级；新服务重试保留原行并补齐 schema。 |
| schema v4 或客户端协议 2 → 本候选 | 拒绝打开/写入，保留数据库。不通过删除库或忽略标记降级。 |
| 相同 C 代码/协议 1、schema 3 的 1.x/2.0.0 命名往返 | 数据与未知字段一致，旧已读值保留并按当前版本重新提示；仅证明命名连续性，不宣称任意未来二进制可降级。 |
| 备份 v1/v2、DB v2/v3、JSON/Gzip | 合成矩阵与 10 份已授权旧备份均通过新旧解码、校验、导入后数据与设置比较。没有使用真实浏览器 Profile。 |
