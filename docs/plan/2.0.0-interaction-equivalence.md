## 5. 有意保留差异

- 旧版任务/清单/菜单大量 span/div 无 keyboard/Escape/focus；新版保留语义化按钮、Escape、焦点恢复、focus-visible。**不恢复这些缺陷**。
- 标签删除清理所有任务 tags，修复旧版“标签位于首位时不清理”的缺陷。
- 报表目标日历保留正确日期，不复刻旧版 2026-11 首行错误；海洋主题兼容 `Sea`/`Ocean`。
- 计时全屏使用原生 dialog，新增 Escape/焦点陷阱；与旧页内全屏的模态语义不同，属于可访问性改善。
- 新版 reduced-motion 覆盖更广。
