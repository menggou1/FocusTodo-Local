## 已交付行为

| 范围 | 实现与依据 |
|---|---|
| 应用壳/导航 | 50px 顶栏；按核心偏好读取侧栏宽度（默认 280px）；预置视图、文件夹展开/收起、搜索和后续视图入口。窄屏菜单在任务详情打开时仍可展开；键盘导航后聚焦视图标题。语言/深色直接订阅核心设置，移除运行入口对 B 样本服务的调用。 |
| 清单/文件夹 | 创建、重命名、父文件夹选择、显示/隐藏、删除确认；管理弹窗提供同组指针/键盘排序与预置顺序恢复。使用 `business.command`，排序提交完整原顺序快照；隐藏/删除及关联任务语义由 C 事务决定。 |
| 任务/搜索 | 创建、改名、清单归属、到期日、提醒、优先级、预计番茄、时长、备注、重复字段；完成/撤销、保留历史的删除确认；搜索任务/备注/子任务使用 C 查询。重复完成生成下一任务及子任务由 C 事务处理。 |
| 子任务 | 创建、编辑、完成/撤销、删除确认；保留 taskId 与现有未知字段。 |
| 任务排序 | 指针拖动与方向键移动通过单条 `updateTask` 原值保护写入 order。无可用浮点顺序槽时拒绝提交并提示冲突，不以多笔无保护写入批量重排。此能力不承诺跨多个任务的原子快照排序。 |
| 冲突/错误/焦点 | 服务事实快照仅订阅；详情草稿保留打开版本，保存以原值检查拒绝覆盖其他窗口。只提交实际修改的字段，不因改名重写提醒秒数或兼容字段。保存失败保留输入；不兼容/需恢复时停写并提供重载。原生 dialog 管理模态与 Escape，关闭返回入口；异步命令完成恢复被禁用控件丢失的焦点。 |
| 本地资源 | 沿用原清单图标与 Noto Sans / Noto Sans SC 字体，`font-display:swap` 保持字体缺失时可用，完整 OFL 文本随候选 `licenses/` 交付。其余素材声明仍受 E17 约束。 |

组件只接收实际剔除 repository 的 `ApplicationServices`；没有 IDB/localStorage 直接业务写入、旧 Redux、旧 DOM 选择器或 `Focus*` 全局依赖。计时、提醒、广播和资源生命周期仍由服务拥有。

## 验证方法与证据

执行入口：

```powershell
npm run build:standalone
npm run package:standalone
npm run test:standalone
npm test
npm run check
# 单独复验本批界面（先构建）
npm run test:workspace
```

`workspace-browser.cjs` 在随机 loopback 子路径、全新浏览器上下文、合成数据、阻断外网下操作生产构建。覆盖任务字段/子任务/搜索、完成撤销/刷新、文件夹及清单编辑隐藏、指针与键盘排序、重复生成、配额失败重试、双窗口冲突、不兼容停写、未知字段与非整分钟提醒保留。中英 × 亮暗分别对照 A 的顶栏/侧栏尺寸及 cfd6449 的字体、行高、高度，注入 30px 越界字体确认断言拒绝；另核对 375px 窄屏裁剪、导航与焦点。截图和 computed style 不替代整个视图的视觉一致性结论。

实际结果与环境见 [本批证据](../acceptance/2.0.0-d1/summary.json)。新输出先进入 `dist/acceptance/`，仅把合成数据的必要摘要和截图归档到 `docs/acceptance/2.0.0-d1/`。测试全局和故障注入不进入候选运行包。两个解压包均通过子路径离线资源启动、创建任务和刷新持久化核对。

## 验收口径

本批是功能接入和局部视觉对照，不能据此宣布 D01/D02 全项或 D 阶段退出。详情当前采用显式保存草稿表单，顶栏操作、任务统计及其他细部与旧基准尚有可见差异；这些差异未视为用户批准。整个 D 的剩余范围、交互与视觉收尾统一在 BACKLOG E09 维护，本报告不建立第二份进度清单。

WebKit 自动化不等于真实 Safari；合成生命周期、替身故障、下载自动化不替代真实系统、真实用户 Profile 和人工体验。真实环境与性能证据按 V02–V07/F 执行。实际发行版本仍为 `7.1.1-local.1.9.3`，schema v3 与备份格式不变，远程 CI 需推送后才有实际结果。
