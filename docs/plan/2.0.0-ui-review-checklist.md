本清单记录本次还原采用的实现方式与需人工确认的差异，不表示用户已验收，也不授权 F、合并或发布。工程及验收状态只在 [BACKLOG E09](../BACKLOG.md) 维护。原则为 **UI 优先、功能兼容、架构服务于实现**。

默认参考是 A 阶段固定 `f102da8919e810006b6611aabcef5f0159057d61` 的可运行 1.9.3，历史截图位于 `docs/acceptance/2.0.0-a/`。对照使用临时来源与独立浏览器上下文、同语言/主题/视口/DPR/时钟及合成数据，阻断外网；从旧版一致快照复制逻辑设置与业务表到候选隔离库。没有访问日常浏览器 Profile 或导入真实数据库。
