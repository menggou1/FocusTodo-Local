## 实际接入

| 范围 | 行为与来源 |
|---|---|
| D02 标签与清单属性 | 新建/编辑/删除标签、清单颜色值保存、任务多标签选择、按标签查看和搜索；沿用 Project type 3000 和 Task.tags。未知兼容 ID 由编辑器保留，不因打开详情清除。 |
| D02 分组/排序 | 按旧版模块 90/917/1122 核对排序值：0 清单、1 到期日、2 优先级、3 自定义；以已提交任务与清单快照投影分组。子任务支持指针与方向键排序；任务支持拖到清单、标签及对应日期/优先级入口，原值检查保护修改。 |
| D01/D02 调宽/统计 | 侧栏分隔线支持指针与方向键调宽，通过 settings 保存到既有 180–380px 范围；任务区四项统计恢复预计时间、待完成任务、已专注时间、已完成任务。隐藏已完成项不改变统计事实。 |
| D03 计时 | 浮动及展开计时器订阅 C 会话；任务/子任务启动后展开，正向/倒计时、暂停/继续、停止、休息/完成、解绑与时长配置走服务。当前关联任务/子任务可以完成，由业务事务与会话解除一起提交。完成任务铃声不改变业务提交结果。 |
| D03 中断恢复 | 显示服务给定的中断区间，用户选择截止点、继续或暂停，支持排除全部中断；精确到毫秒的本地输入避免把区间起点向分钟取整。关闭恢复弹窗后可从计时控件再次打开，未确认前不能启动新的写入流程。 |
| D03 声音 | 复用全部本地背景音与铃声选项、试听/停止试听、两类音量及任务完成音设置；音频所有权和释放仍归 C。无原生 Web Locks 时说明自动背景音降级，手动试听保留。 |
| D03 迷你窗口 | 原生 Document PiP 使用 React portal 与共享会话/命令，不创建第二个写入者；同步时间、任务、主题、开始/暂停/继续/停止，支持关闭与重新打开。不支持或打开失败时保留可操作的页内计时并给出提示。 |

旧版取证仅在开发期间读取稳定入口的旧组件及 `local-timer-ui.js`。候选运行时不导入旧 bundle、不使用旧模块编号或 Redux。停止/模式/休息行为按实际本地适配路径核对，不能只按上游未被调用的方法推断。

## 验证

执行 `npm run build:standalone`、`npm run package:standalone`、三引擎 `workspace-browser.cjs`、候选 `browser-acceptance.cjs` 及 `package-smoke.cjs`。工作区回归覆盖标签/颜色值、分组、侧栏宽度持久化、跨清单拖动、子任务指针/键盘排序、计时片段及 25 秒阈值、任务关联、模式重载、中断排除、休息流程、声音偏好和迷你降级。Chromium 另实际打开原生 PiP，操作开始/暂停/停止并核对只存在一个 TimerSession。这里只验证媒体调用与偏好路径，不称为真实系统试听验收。

本批摘要、环境及实际数量见[证据](../acceptance/2.0.0-d2/summary.json)。D01–D03 视图继续在中英、亮暗、375px 窄屏和减少动态效果条件下检查；既有 A 几何/排版断言及注入反例保留。本批不开展 D-V 集中视觉还原，也不产生用户视觉认可结论。

## 交付边界

D 整体仍在实施中；后续页面及原交互细节统一在 BACKLOG E09 维护。当前部分路由仍明确显示未接入提示，不计入任何完成项，不能作为 D-R 候选交付。尤其不能把任务详情当前显式保存、重复字段表单等交互差异归为字体/颜色差异而跳过恢复。

D-R 只在 D 全部必要功能与全页面渲染/操作验证通过后交付。届时提供运行预览、启动说明和已知差异清单，停止后续开发等待用户审查；用户完成审查并明确授权之前，不进入 D-V、E 或 F。WebKit 仍不是实际 Safari，系统音频、通知与真实 Profile 的验收边界不变。
