## A03：静态存储清单与维护顺序

`local-data.js` 声明的 store / keyPath / 索引：Project/id（state、sync、parentId）；Task/id（projectId、deadline、reminderDate、finishedDate、sync）；Subtask/id（taskId、sync、finishedDate）；Pomodoro/id（taskId、subtaskId、endDate、sync）；Schedule/id（taskId、subtaskId、endDate、sync）；Group/groupId（groupLeader、createdDate、secret、membersNum）；GroupUser/id（groupId、uuid、sync、name、todayPomodoroTime、weekPomodoroTime、focusEndDate）；Message/messageId（groupId、userId、state、sync、creationDate、replyUserId、replyMessageId、parentId、username）；TimerSession/id、LocalMeta/id（均无声明索引）。锁库 ownership 是单独数据库。现有 `docs/ARCHITECTURE.md` 的 Group 索引表遗漏 `membersNum`，以代码及真实库检查为准。

使用 `bundle-editor.cjs` 的 Acorn AST 遍历旧包，对直接 `localStorage.getItem/setItem/removeItem` 的字面量键取样，模块 13 是主要偏好读写者：计时 WorkInterval、ShortBreakInterval、LongBreakInterval、LongBreakPomodoros、AutoWork、AutoBreak、BanBreak、Countdown；声音 TskCmpSnd、WorkAlarm、BreakAlarm、BgMusic、RtnVol、WNVol；任务 NewTskOnTop、DefaultDeadline、ShowFinishedTasksInToday、timingTaskId、timingSubtaskId、LastReminderDate；外观 DarkMode、ProjectRegionWidth、Forest；历史/兼容 Version、ExpiredDate、LstRlsVer、UpdAltCnt、UpdAltDate、UpdateV64Data、UpdateTasksData；资料 Portrait、AvatarTimestamp；其他云/旧功能及更新键 ConfigTimestamp、ServerTimestamp、SyncTimestamp、SelectedGroupId、Receipt、Price、PriceUSD、PriceInfo、ServerAccessInfo、ServerUrls、PK1、UploadExpiredDate、GroupIntervalIncrement、OverseaServerUrl、RegionCode、PrevRank30、PrevRankAll、PrevRankForest、LastSyncFocusTimeAll、LastSyncSunlight、InstallationDate、HasRated、ShowRateDialog、Group、RnkLst。其他模块直接读写 Theme、Goals、WidgetExpanded、AllWidgets、Widgets。动态键（例如 `cookie.` 拼接）及本地模块不在该静态提取范围；不应据此删除未知键。偏好默认值、动态访问和历史版本变体仍需逐项核对。

导入时以独立 IndexedDB 长事务持有 ownership 锁，并以可选 Web Locks 和同页队列串行；主库 LocalMeta 保存维护标记和 settings-journal，先持久化快照/日志，再应用 IndexedDB 与设置，失败时恢复，恢复失败保留日志供下次启动处理。旧管理器直接使用的 db.transaction 被包装以检查标记；BroadcastChannel 通知维护、替换、任务、日程及计时刷新，但不承担唯一互斥保证。`onversionchange` 关闭连接，blocked 提示关闭旧标签。旧版本是否执行同样协议尚未证明；不能让不受控版本并发写入。导出保留存储快照的未知兼容键，排除内部主题日志。
