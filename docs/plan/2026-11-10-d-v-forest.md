## 修改依据和行为

| 项目 | 1.9.3 事实 | 本轮结果 |
| --- | --- | --- |
| 动作按钮 | [local-controls.css](../../src/local-controls.css) 定义 36×36、margin 6px、蓝底/3px 边框、200ms `ease` 的 1.05 倍 hover；focus-visible 为红色 2px、offset 2px | 保留原有缩放、背景、边框、焦点及禁用反馈；实际按钮盒取代外部伪元素圆形 |
| 全局 hover | 原版按具体控件定义 hover，没有所有按钮统一背景 | 删除 `workspace.css` 中 `.workspace-shell button:hover,.workspace-dialog button:hover` 的统一背景；保留菜单、选项等专用 hover 规则 |
| 关闭和阳光按钮 | 旧关闭图标/阳光节点没有背景变色或焦点圈 | 本轮目标中的鼠标、按下及键盘 focus 状态没有额外绘制；保留新版按钮语义及操作能力 |
| 动态/攻略滚动 | [main.css](../../src/main.css) 的 ScrollView customContainer/customTrack/customThumb：6px、右侧 2px、3px 圆角、透明轨道，无原生槽占位 | 复用 `LegacyScrollbars`；森林使用局部定位轨道，跟随抽屉移动；保留原生内容滚动及真实滑块拖动 |
| 成就滚动 | 原版 RankingList 的 userList 是原生列表 | 按用户本轮补充要求修复旧版缺陷，同样使用 ScrollView 外观和行为。这是明确的授权差异 |
| 滚动比例 | 动态行最小 48px；攻略段落行高 1.42857143，标题 1.1 | 修复目标内文字行高，内容高度与可见滑块比例匹配；没有裁剪内容或禁用滚动 |
| 抽屉 | [main.js](../../src/js/main.js) 的 DrawerView 挂载后 10ms 设 visible，transform 从 100%→0%，300ms `ease`；关闭反向，300ms 后 onClose 卸载 | 活动列表保持挂载，独立抽屉覆盖其上；从右向左进入、向右退出，没有额外遮罩或内容 fade；沿用旧版关闭图标 |
| 阳光 | [local-achievements.js](../../src/js/local-achievements.js) 的 collectItems 同时启动可见球，1000ms `ease-in-out`、scale 1→0.2、opacity 1→0；持久化独立于飞行，结束后树木 800ms 脉冲 | 点击任务内即启动 WAAPI，持久化并行；采用几何等价的 transform/opacity 使飞行可合成；冻结飞行期间可见节点顺序，提交成功节点先隐藏再移除，失败节点可重试 |

轨道默认隐藏，边缘/滑块 hover 高亮，滚轮显示普通滑块；离开或空闲约 1000ms 后用 200ms 淡出。普通滑块 `rgba(200,200,200,.5)`，高亮 `rgba(174,174,174,.7)`，高亮内阴影 `inset 0 0 6px rgba(0,0,0,.3)`，最小滑块 30px。原版攻略翻译完成后，隐藏滑块可能暂存旧高度；一旦首次 hover 即重新计算并与新版一致，未将不可见的暂存值作为视觉差异。

飞行中心终点保持 `(W/2, 0.84H)`，本轮场景为 `(190,375.48)`。对任一当前起点 `S`，中心为 `S+(T-S)E(t)`；`E` 是原版 ease-in-out。各球的缩放和透明度共用该进度，没有减少球数、分段跳转或缩短飞行时间。业务服务及奖励算法没有修改。

## 文件与复核入口

生产修改仅四个文件：`Forest.tsx`、`LegacyScrollbars.tsx`、`legacy-forest.css`、`workspace.css`。增加六个 `tests/standalone/forest-*.cjs` 取证/回归脚本；同步三个既有测试的抽屉关闭选择器和 WAAPI 断言。文档为本报告及 BACKLOG 本轮段落。

全部当前生成证据只在忽略目录 [`dist/acceptance/d-v-forest/`](../../dist/acceptance/d-v-forest/)：

- [`index.html`](../../dist/acceptance/d-v-forest/index.html)：完整面板、录像、关键帧、日志和 JSON 的集中入口。
- `ui-results.json`、`flight-results.json`、`hover-regression.json`、`collection-boundaries.json`、`continuous-results.json`：逐项断言及真实时序。
- `*-continuous-old/new.webm`：未暂停打开/关闭与收取录像；`*-flight-old/new.webm` 和不含 continuous 的 UI 录像用于确定性关键帧检查，包含测试主动暂停/回放，不能当作自然流畅度录像。
- `baseline/refined-*-trace.json.gz` 可在浏览器 Performance 面板载入，`*-cpu.cpuprofile` 为 CPU 栈，`*-performance.json` 保存原始 rAF/提交/DOM 更新记录；`compositor-diagnostics.json` 保存合成证据。
- `environment.json` 为 Tag、实际 HTTP 内容摘要、合成数据、视口与 HMR 核验；`delivery.json` 为本地提交及交付摘要。

复跑：`node tests/standalone/forest-ui-equivalence.cjs`、`forest-flight-equivalence.cjs`、`forest-hover-regression.cjs`、`forest-collection-boundaries.cjs`、`forest-motion-recording.cjs`；性能为 `node tests/standalone/forest-parity.cjs <采样名称>`。从仓库根目录执行，预先保持 5511/5513 可用。
